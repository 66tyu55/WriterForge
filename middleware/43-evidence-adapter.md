# 43 Evidence Adapter｜学习证据适配器

## 目标
把“学海库里学到的东西”转换成 WRITE 能安全使用的写作提示。

## 输入
可以来自：
- 方法簇
- 词域
- 句子功能
- 节奏模式
- 感官策略
- 跨作品对照

## 输出示例

```yaml
writing_guidance:
  function: 压住愤怒，不立即爆发
  possible_routes:
    - 动作被迫停住
    - 先处理手边小事
    - 对白变短
    - 感官注意力变窄
  avoid:
    - 直接写“他很愤怒”
    - 连续使用相同身体反应
```

## 禁止
- 把原著句子原封不动送给 Draft Skill
- 把高权重句子当模板
- 保留源句语序让 WRITE 改名词
