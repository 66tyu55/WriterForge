# Hot Skill Assimilation Plan

This pass inspected high-install / high-visibility Agent Skill repositories and mapped their useful mechanisms into WriterForge without increasing the number of always-on fiction skills.

## P0 — assimilate into existing owners

### Evolution Engine
Absorb:
- candidate vs baseline evaluation;
- root-cause-first failure diagnosis;
- reproduce-failure-before-fix;
- verification before promotion;
- held-in + held-out no-regression acceptance;
- raw-trace archive;
- fix failures at the lowest adequate optimization rung.

Do not let the proposer edit:
- evaluator implementation;
- promotion thresholds;
- immutable regression corpus;
- permission/budget enforcement.

### Reactive Runtime / Memory
Absorb:
- context pointers and progressive disclosure;
- one source of truth;
- no-op and sediment pruning;
- anchored incremental compression;
- artifact/identifier preservation;
- probe-based recovery tests;
- context degradation detection before context expansion.

Novel-specific adaptation:
- protect Canon facts, current Character State, open Promises, current Scene Contract, and accepted-prose pointers as structured anchors;
- compressed prose summaries are caches and must carry source revision fingerprints.

### Character Engine
Absorb BDI separation as an implementation aid:
```text
fact != belief
belief != desire
desire != intention
intention != action
```
This strengthens existing false-belief, partial-awareness, private/public-goal work. It does not create a new Character Skill.

### Promise / Reader Memory
Replace fixed “10 chapters absent” reminders with a **Dormancy Signal**:

```text
dormancy =
importance
× reader-memory decay
× expected-return-window breach
× unresolved-pressure
× genre sensitivity
```

A dormant element may be intentionally quiet. The signal routes to Story Sense; it does not force a callback.

## P1 — merge during the next craft/story pass

### Discovery / Multiscale
From writing-fragments / beats / shape:
- preserve unstructured noticings during discovery;
- do not force all discovered material into the final work;
- track what the reader has already been grounded to understand;
- each paragraph/beat should change what the reader can know, feel, infer, or expect.

Novel adaptation: “grounding” is not exposition. A concept may be grounded by action, implication, dialogue, repeated context, or reader inference.

### Story Stress Test
Use the grill pattern only at:
- Book/Arc planning;
- structural revision;
- suspicious causal shortcuts;
- Evolution training.

Never run it sentence-by-sentence.

Questions target:
- what assumption makes this event possible?
- what happens if the character refuses?
- what information is actually available?
- which coincidence is carrying too much load?
- what changes if this scene is removed?

## P2 — watch

- generic brainstorming workflows;
- multi-agent orchestration patterns;
- genre template skills;
- document coauthoring;
- generic visual taste systems.

They may supply mechanisms later, but are not production dependencies now.

## Pruning rule

Every assimilation must answer:

1. Which existing owner receives it?
2. Which current rule becomes obsolete?
3. What new failure can it detect or prevent?
4. What regression test proves the gain?
5. Does it change ordinary WRITE latency?

If question 2 has no answer for a near-duplicate mechanism, default to MERGE or REJECT rather than adding another instruction.
