# 子技能 13：跨作品同效果 / 异效果对照器

## 目标
比较两部或多部原著：
“它们都想达到恐怖/搞笑/热血等效果时，分别怎么写？”
以及：
“它们使用相似材料时，为什么产生不同效果？”

## 禁止
不得只把两本书各摘几句放在一起比较。
必须从**完整小场景**或**连续段落**出发。

## 对照维度

### 输入
```yaml
effect_target: 恐怖
source_A:
  work:
  chapter:
  scene_span:
source_B:
  work:
  chapter:
  scene_span:
```

### 分析
1. 场景前状态；
2. 第一处异常从哪里出现；
3. 信息隐藏多少；
4. 人物是否知道危险；
5. 读者是否比人物知道得更多；
6. 使用什么感官；
7. 句长变化；
8. 动作密度；
9. 是否直接命名情绪；
10. 高潮前是否留白；
11. 高潮后的处理；
12. 最终让读者留下什么感觉。

## 示例：同样是“恐怖”
可能出现完全不同的机制：
- A：靠未知和留白；
- B：靠身体感和空间封闭；
- C：靠日常事物出现微小异常；
- D：靠人物知道危险却无法离开。

## 示例：同样是“搞笑”
可能出现：
- 角色认知差；
- 身份反差；
- 严肃叙述配荒唐结果；
- 节奏突然打断；
- 语言误解；
- 行为后果。

## 形成“效果方法库”
存的不是句子，而是：

```yaml
effect: 恐怖
method_id: HORROR-UNKNOWN-01
mechanism: 延迟解释，让异常先于原因出现
best_for:
  - 陌生空间
  - 角色信息不足
risks:
  - 过度使用会拖沓
evidence:
  - workA-ch3-sc2
  - workB-ch7-sc1
```

## 最终目的
让 AI 明白：
“同样的效果有多条路可以到达”，避免把一个原著的写法误认为唯一正确写法。
