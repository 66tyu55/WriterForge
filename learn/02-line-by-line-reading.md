# 子技能 02：逐句阅读 + 旁路候选

## 目标
除了 8 条事实轨道，再逐句学习“为什么这一句出现在这里”。

每读一句，回答：
1. 上一句留下了什么未完成的东西？
2. 本句承担什么功能？
3. 本句新增了什么？
4. 本句隐藏了什么？
5. 本句如何把读者推向下一句？

## 文笔维度
逐句记录：
- 句长；
- 停顿方式；
- 主语是否省略；
- 动词密度；
- 名词具体度；
- 修饰词密度；
- 感官通道；
- 信息先后；
- 动作/观察/判断/对白的类型；
- 句尾落点；
- 与前句的重复或反差。

## 旁路候选模式
当创作主控不知道下一句时，本技能不直接替它写定稿。
先根据当前场景生成 3–5 个“方向候选”。

格式：

```yaml
option_1:
  function: 推进一步动作
  example: <原创示意句>
  introduces_new_fact: false
  risk: low
option_2:
  function: 转入听觉感知
  example: <原创示意句>
  introduces_new_fact: false
  risk: low
option_3:
  function: 暂停动作，暴露人物犹豫
  example: <原创示意句>
  introduces_new_fact: false
  risk: medium
```

## 原著参考方式
旁路候选可以查询学海库中的“相同叙事功能”案例，但只允许读取：
- 功能标签；
- 节奏标签；
- 感官标签；
- 短小证据；
- 抽象结构。

不得：
- 复制原著整句作为候选；
- 只改人名后输出；
- 把原著多个句子拼为候选。

## 选择后
选中候选只代表选中“功能方向”，创作技能仍须重新生成最终句。
