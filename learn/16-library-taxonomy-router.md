# 子技能 16：学海库分类路由器

## 目标
防止所有文学原著混成一锅。

## 顶层库建议

```text
学海库/
  现代小说/
  西方小说/
  中国古代小说/
  中国玄幻小说/
```

这只是第一层，允许继续细分。

## 推荐元数据

```yaml
library_class: 中国玄幻小说
culture: 中国
period: 架空古代
genre: 玄幻
subgenre:
  - 东方玄幻
tone_capabilities:
  - 热血
  - 神秘
  - 恐怖
source_role:
  - core
  - auxiliary
```

## Core 与 Auxiliary

### Core
对目标类型核心机制有直接贡献。
例如目标为中国玄幻时：
- 世界规则；
- 力量体系；
- 宗门/修炼生态；
- 超自然冲突；
- 玄幻场景节奏。

### Auxiliary
不是目标类型核心，但某方面非常有价值。
例如：
- 中国古代小说 -> 古代生活、礼制、器物；
- 现代小说 -> 对话、都市人物关系；
- 西方小说 -> 悬疑结构、某类恐怖机制。

## 调用原则
创作“中国玄幻”时：
1. 先查“中国玄幻小说/Core”；
2. 若当前问题是古代器物，再查“中国古代小说/Auxiliary”；
3. 若需要“恐怖机制”，可跨库查方法，但不得未经转换直接引入文化专名。

## 禁止
- 默认跨库混用专名；
- 把西方中世纪语汇当成中国古代语汇；
- 因为效果标签相同就忽略文化语境。
