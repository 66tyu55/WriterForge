# Writer Maturity L1-L10｜小说家成熟度

| Level | 质变能力 |
|---|---|
| L1 | 能生成小说文字，但几乎没有长篇控制。 |
| L2 | 能维持基础人物、世界、剧情连续性。 |
| L3 | 能规划并稳定完成章节与基本故事弧。 |
| L4 | 人物依据自己的知识、目标、恐惧、信念和关系行动，而非剧情木偶。 |
| L5 | 能根据场景功能主动选择文学技法，不再用同一种渲染方式写所有场景。 |
| L6 | 能从完整原著与真实读者证据学习“机制→效果”，并迁移到陌生作品。 |
| L7 | 能控制长篇回声：人物弧、承诺、母题、声音、记忆与累计意义。 |
| L8 | 形成 Story Sense：能识别当前最主要的文学问题，也知道哪些正确规则此刻不重要。 |
| L9 | 能主动发现自身文学短板、设计训练、升级 Skill，并用陌生题与外部读者证明迁移。 |
| L10 | 能在不同长篇项目中持续做出作品自身的文学判断，而不是依赖固定公式。 |

## 晋级原则

- 只允许一次晋一级。
- 必须写清 `Capability Statement`。
- 不允许用训练题成绩证明迁移能力。
- 不允许只凭 AI 自评晋级。
- 子 Skill 存在未解决 Capability Lag 时，不允许整体晋级。
- 一次局部 Skill 升级不等于 Writer Level 自动提升。
