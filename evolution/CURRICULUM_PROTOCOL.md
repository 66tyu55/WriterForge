# Literary Curriculum Protocol｜文学能力训练

## 目标

让 WriterForge 针对真实小说创作弱点训练，而不是刷固定模板。

## 一题只练一个主要 Lever

训练任务应尽量隔离目标能力，例如：
- Dialogue Subtext
- Cognitive Motion
- Character Entrance
- Scene/Summary/Omission
- Motif Return
- Psychic Distance
- Strategic Reversal
- Narrative Restraint

不要把“人物、世界、反转、文笔、节奏”全塞进一个练习再声称某项能力提高。

## Frontier 原则

题目应位于“当前差一点能稳定做到”的能力边缘：
- 太容易：不进入 Curriculum；
- 无法评价/无解：丢弃；
- 与训练样本高度重复：丢弃；
- 需要目标能力但更换了人物关系/压力/信息结构：优先。

## 场景验证

Scenario Verifier 检查：
1. 真正在测目标小说技法吗？
2. 是否泄露预期答案？
3. 是否存在足够多合法写法，而不是唯一标准答案？
4. 是否可以从 Reader Effect / Story State / Pairwise Preference 得到可解释反馈？
5. 是否和既有训练场景重复？

文学题目不是数学题，因此验证的是能力证据，不是标准句子。
