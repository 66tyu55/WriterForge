# 子技能 04：主动删除与重写

## 目标
让 AI 能像作者一样删掉自己刚写的内容，而不是默认保留。

## 每句接受前四问
1. 删除这句，段落是否更好？
2. 这句是否只是解释已经展示过的内容？
3. 这句是否抢先说了下一步本应由动作表现的信息？
4. 这句是否因为“舍不得删”才存在？

任一答案为“是”，进入删除候选。

## 删除范围
允许：
- 删除当前句；
- 删除前一句；
- 删除整个刚完成的小段。

禁止在没有回读逻辑链的情况下大面积重写前文。

## 删除后
若出现断口：
- 调用 02 的旁路候选；
- 生成 3 个桥接方向；
- 再由 03 写一句。

## 删除记录
```json
{
  "deleted_text": "...",
  "reason": "重复解释",
  "replacement": "...",
  "effect": "节奏加快"
}
```

## 思考无果
若连续删除 >= 3 次：
1. 暂停产出；
2. 回读最近 5–10 句；
3. 检查段落目标是否错误；
4. 检查人物当前意图是否缺失；
5. 调用 09 查看未来走向；
6. 由 02 提供不同功能的候选，而不是同义改写。
