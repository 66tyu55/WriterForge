# WriterForge V7 Eval Protocol

## 三组对照
A. Bare model
B. Ordinary outline prompt
C. WriterForge

同一个 seed、同一个篇幅目标、同一模型配置。

## 机器指标
- Canon conflict
- Knowledge leak
- Dead-character action
- Item/location conflict
- Timeline conflict
- POV leak
- Missing causal trigger
- Forgotten promise
- World-rule conflict
- Repetition / retrieval-source concentration
- Source-overuse

## 人类盲评
评审不知道 A/B/C 来源。

重点不是“文笔漂亮”单项，而是：
- 是否想继续读
- 人物是否像活人
- 因果是否可信但不机械
- 是否有意外但不随机
- 声音是否可辨认
- 读完是否留下情绪残留
- 是否太可预测
- 是否有明显 AI 整齐感

## 失败原则
如果 WriterForge 只在一致性指标领先，却在人类“想继续读”上下降，
不得宣布系统成功。
