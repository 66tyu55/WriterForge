# 28 Memory Budget / 长篇记忆预算

## 目标
小说越长，不能把所有正文都塞进上下文。

## 五层记忆
```text
L0 当前句
L1 当前场景
L2 当前章节
L3 当前卷
L4 全书 Canon
Archive 原始正文
```

## 当前写作只加载
- 当前场景契约；
- 当前人物状态；
- 当前相关 Canon；
- 开放伏笔；
- 最近因果链；
- 当前读者状态；
- 必须承接的未来节点。

## 压缩原则
旧内容压缩为：
- 已成立事实；
- 未解决问题；
- 关系变化；
- 物品变化；
- 角色知识；
- promise/payoff 状态；
- 重要语气/风格证据。

## 禁止
压缩时不能把：
“计划”
写成
“已经发生”。

## 检索预算
单次检索优先相关性，不追求数量。
