# 23 场景契约 / Scene Contract

## 目标
保证逐句写作不会失去场景方向。

## 写场景前必须有
```yaml
scene_id:
pov:
location:
time:
entry_state:
pov_goal:
opposition:
stakes:
scene_question:
required_beats: []
turning_point:
exit_state:
new_question_created:
```

## 场景合格条件
- 入场状态与离场状态不同；
- 至少有一个人物选择或外部变化；
- 场景问题有推进；
- 场景不是纯信息倾倒。

## 句子层级关系
场景决定方向；
段落决定微目标；
句子只解决当前最小动作。
