# 24 伏笔 / 承诺 / 回收账本

## 目标
不只记录“伏笔”，还记录小说向读者做出的期待承诺。

## 类型
```yaml
promise_type:
  - mystery
  - foreshadowing
  - oath
  - threat
  - prophecy
  - unexplained_object
  - relationship_tension
  - power_ceiling
  - world_question
```

## 条目
```yaml
promise_id:
created_at:
reader_question:
importance: low|medium|high
expected_window:
hints_given: []
false_leads: []
payoff_plan:
status: open|developing|paid|abandoned
```

## 强制检查
- 高重要度承诺不能长期失踪；
- 回收前应检查是否有足够铺垫；
- 不允许临时制造“其实早有伏笔”；
- 废弃承诺必须显式记录原因。
