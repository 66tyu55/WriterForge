# 25 读者信息状态

## 目标
分别管理：
作者知道什么、人物知道什么、读者知道什么。

## Reader State
```yaml
reader_knows:
reader_suspects:
reader_believes:
reader_false_assumptions:
reader_questions:
reader_expectations:
```

## 用途
可设计：
- 悬念；
- 谜题；
- 惊讶；
- 戏剧性反讽；
- 错误引导。

## 检查
每个关键揭示前先确认：
- 读者是否已经被暗示；
- 揭示是不是太早；
- 读者是否比 POV 人物知道更多；
- 这是否是有意设计。
