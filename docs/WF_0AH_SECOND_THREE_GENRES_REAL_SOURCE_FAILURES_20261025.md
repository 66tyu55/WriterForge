## 3. 真正的来源、知识与因果风险

所有三份 WF 原文均由 V96 找到真实且顺序正确的 `action_quote/effect_quote`，但回执的 `causal_relation_verified=false`；V116/V122 对三组未报物件硬矛盾或来源关系待审。这只证明检查器在现有覆盖范围内没有触发，并非文学因果正确。

### 仙侠：未知采摘者与可能的来源错配

WF 真正的 `action_quote` 为“她退回廊下，没开门。”，`effect_quote` 为“土上印着一只浅鞋印，在她开门之前就有了。”，两句字面顺序合法，却**不证明“不打开门”造成了旧鞋印**。角色的观察、怀疑、确定有区分，但“开门前已经触碰土壤”的可达性是否合理取决于未交代的围圃布局；“灵壤三十六升，摘一篮后记已取七升、余二十九”算术成立，**灵壤减少七升与采药动作之间的资源同一性没有来源证明**。这些是具体、可追查的**来源欠债/关系疑点**，当前不是确定的硬物理矛盾。

裸模型在门未开的情况下断言“谁也没进去”，也可能越过已知事实边界，除非此前明确只有一扇未动的门。不能因为此漏洞发生在裸组就替 WF 抹掉本组自己的缺陷。

### 历史：传令时间成立，但标记与马蹄并非已证明的直接因果

WF 写到“申时末来信、驿马换过两匹、最早明日卯时递交主帅”，没有凭空让主帅立即获知情报，应作为**防假红**的合法时间流样本。其 `action_quote` 是整理方位、时辰与换人传递标记；`effect_quote` 是搁笔时听见营门外马蹄、抬头未起。马蹄可以来自信使，也可以来自其他人，**不能从并置引句推出标记导致马匹起行或消息已经到达**。保留此不确定性而非拒绝整个文学片段。

### 喜剧：合法间接因果、信息差与节奏的正面样本

WF 文本通过“阿桃把袋子递给老周→新客到店说明订单→双方交谈→解除误会”的中间事件把笑点展开。这个链条允许正常省略和人物信息差，**不能因为动作和后来笑声不相邻就硬判因果错误**。较长篇幅和最后三人一同发笑略显公式化，属文学自然度的读者判断，不是 WF 应该自动删句的证明。真实长短差异让 +3.0 分**不可作效果归因**。

## 4. 已证实软件错误的 RED → 原模块修补 → GREEN

**真实 RED**：`provider-originals/comedy_breakfast_blind-1.json` 来自 #40201458798，原始 provider raw SHA256 为 `9ad03b5df68624e0b5ec956024915111a6f36ef31182902277bc2a5b70cd2e2f`。评委实际输出 `{type:'json_object',ratings:{甲:{...},乙:{...}},note:'...'}`，两个真实分数 **76/72** 在原件中完整存在，但评分消费路径旧 `normalize` 仅接受 `ratings` 与可选 `type`，报 `WF0AD_MODEL_SCHEMA_INVALID`。额外 note SHA256 为 `67a467a94a2c88e129775e90e1c03bdf3e7eb91147a30f01fb242849611d04a4`。

**原模块修补**：`experiments/wf_0ag_diverse_micro_paired_20261025.py` 的源评分解析器 `parse_micro_judge` 仅接受**有界** supplementary `note` 字段，保留原官方原件及附注 SHA，评分时无损排除附注；陌生字段、布尔分数、缺标签及超长附注仍按异常处理。`experiments/wf_0ah_diverse_micro_paired_20261025.py` 现在复用该已有评分解析器，不再维护第二套相同评分规则。

**GREEN**：`tests/test_wf_0ah_real_comedy_grade_note_repair.py` 将真实格式、note SHA 和拒绝未知字段纳入回归；`tests/test_wf_0ah_source_only_one_reverse_protocol.py` 保证先原件 SHA 核验、再唯一一次合法评分。最终 #40202483990 **全部1,736测试中1,726通过/10跳过，0失败**，付费重问作者次数0，补缺失逆序评分1次，来源和分数恢复成功。第一个补评流程中的离线测试错误没有触发任何付费调用，真实已有回包从未被覆盖。

## 5. 下一轮真正的 WriterForge 核心问题（不能只增词表或提醒作者）

**必须先构造跨体裁 RED**：V96 对 `decision` 强制要求 `action_quote` 和 `effect_quote` 都非空。这可能驱使模型把后来的巧合、未明确触发的马蹄声、旧鞋印或修辞性结语**凑成后果引句**，从而形成“来源顺序合法、真实因果没有成立”的结构性漏洞。此机制限制是代码可见的，但“模型是否因此凑引句”的因果归因**尚未通过对照实测确认**，不能声称已修文学底层。

建议用至少三类**不同合法场景**对照：决定等待但本段尚无外显结果、行动造成可见物理变化、动作和结果由无关中间事件隔开。尝试在已有 V96/V98/NarrativeCore 里表示**action有来源、effect待实际观察**的候选状态，并测试下游是否会不小心将它提升为已知事实。**未证明前不得为了刷新绿灯放宽V96硬闸或强制AI编写结果。** V114/V117/V119 的后文依赖必须在修改后重验，而合法省略、认知有限、安静收束不应产生假红色。

后续四类原创题仍未实际生成：**言情旧照片、日常钥匙、科幻灾难压差、初雪抒情**。同题、同模型、每次200～350字、原回包 SHA、双顺序分数与独立来源审计必须继续；这四题不能替代真实软件 RED→FIX→GREEN。文学技巧参照成熟原著只允许WF自身只读检索相同文学任务的局部窗口，不得由宿主复制句子、人物或剧情。
