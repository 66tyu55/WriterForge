# WF 人物生态 Skill｜2026-11-18 首版交接

**已建立**：`.agents/skills/wf-living-ecology/SKILL.md`、对应 `scripts/ecology_shadow.py`、`tests/test_wf_living_ecology_shadow.py` 和隔离 CI 工作流。

**目标**：每个普通人或重要人物都能有独立的需要、认识和计划；没在主角面前出现时照样生活。读者看到的是一个局部视角，而非全部幕后解释。角色可以永不再次出现，也可不采取行动；不许强制人人有秘密、反转、支线或伏笔回收。

**复用**：既有 `writerforge/narrative_core.py` 保存人物关系与长期线索，V114/V116/V117 保存有限物件/时间事实。本轮脚本是 **SHADOW 协议验证**，并非第二个 Canon、生产数据库或自动作家。

**首版已写入的可检验功能**：
1. 各人物只获得自己的 `knows/believes/concern/private_plan/resources/constraints`；其他人的私有信息不传递。
2. `WAIT/ACT/RECONSIDER/DECLINE` 是外部人物决策可提交的类型，不由校验器替人物选择。
3. 只有明确提交的事件候选进入世界；意图不自动变成成功事实，且每次候选需要来源引用。
4. `writer_view` 仅展示公共或当前 POV 真正目击的结果，不展示其他人的私心，也不要求将后台事件写进正文。
5. 有 7 个单元测试，覆盖人物私心泄露、旁人行动不经主角授权、没有行动就不产生事件、重复事件 ID/未知见证者拒绝、不可强制每件事曝光、示例不宣称模型训练/文学提升。

**核验状态**：GitHub 提交与文件内容回读已证实；提交了 GitHub Actions 窄范围隔离测试工作流。**当前未取得工作流执行的 SUCCESS 结果，不声称 7/7 已运行通过。** 没有运行独立模型人物决策、没有付费调用，也没有 A/B 正文盲评。因此当前是“可运行隔离协议原型”，**不是已证明的自治生态**。

**下一步仅测试一件事**：同一个真实场景，各人物分别获得有区别的有限信息，以真实模型调用独立产生决策，再冻结事件前后状态，用原作者模型写可见正文，与裸写对照。记录后台强制预设的痕迹密度，以及人类读者能否察觉刻意安排。若更僵硬则放弃，不扩容。
