- **《西游记》第001回**：`https://zh.wikisource.org/w/index.php?title=西遊記/第001回&oldid=2562136`；核对实际文本“石猴入水帘洞—公开诺言—群猴承诺—地位变化”和“樵夫提供路线，却因照料老母和生计无法同行”。这不是笼统的“勇敢”“NPC有个性”，而是**先立赌约/现实利益/他人是否兑现**与**配角自己的不可替代责任**。

- **没有把网页全文下载进仓库**，也没有宣称全页字节 SHA。固定 oldid 与锚点哈希只能证明哪一段被人工定位；不能证明底本同一、全文校验或独立人类审稿完成。

## 目前的真实阻塞（绝不可假装完成）

1. **古籍版次**：维基文库 oldid 已定位，但拿不到这次固定修订的全页原始字节/可复核电子底本 SHA。内部西遊记测试文本与页面不同，不能“算出”网站 SHA；《史记》没有完整锁定字节原件。
2. **审核权限与版权**：历史文本公有领域不代表所有现代校注/数字编辑内容均无须审核。当前 `PILOT_APPROVED` 是方法卡在原测试中的权限标签，`review_receipt_sha256` 本身只是一个 SHA 字符串，**不是独立审核人的签名/商用授权证明**。在真实古籍进入正式 WRITE 前需要可信审阅批准来源及权利范围；新研究卡绝不自我升格。
3. **真实文学增益**：没有新的经过授权的足够强作者模型请求、没有实际 provider 原始回包/token/美元计费，也没有真人独立盲评。因此本轮不能声称 WF+学海优于 WF 核心，更不能把源码的 GREEN 数量当作文学质量。
4. **现代玄幻来源**：未经合法授权不能从用户 R2 / 网页复制《凡人修仙传》等原文。先以有许可证的古籍与真实原创测试场景推进，并记录失败。

## 下一个切实的研发步骤

- 先选 **1—2 个短方法**，分别核实可使用的真实电子底本及出版版本、来源 SHA、版权标记、人工（非 AI 自称）审核。优先水帘洞的“公开承诺→探索资源→身份变化”和樵夫的“知情人独立生计”，不是宏观世界大纲或通用审稿规则。
- 核对审阅凭证的信任根；当前单个 SHA 不足以授权。与现有 XuehaiStore 及 DB 关联，不开发第二套记忆。
- **之后**在新的明确模型、总调用次数、费用上限授权下，对同一原创玄幻场景执行三臂：A 裸作者，B 原真实 WF G，C 相同 G+审核后最多2张方法卡。C 只额外送达具体认知机制、不得强制选剧情或复制来源。
- 用**真实作品全文及费用**判断是否值得继续：先排除复述、长度违约与方法错配，再核对人物选择的因果、对配角的尊重、细节是否自然、语言与情节新意。无明确增益则停用卡；不重新采样无效小模型，不堆规则，不发布。

**代码和数据未对生产启用本轮古籍方法。本轮真正新增的是经过字节校验的完整原文结构学习隔离样本、4个深入原文的具体方法研究候选与可靠的版权/版本阻止机制，而不是训练了经典名著。**
