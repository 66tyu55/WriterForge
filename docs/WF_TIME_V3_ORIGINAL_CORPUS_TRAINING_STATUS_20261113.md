## 2. 原著直接暴露出的参数缺口

以下均为源文阅读后的抽象归纳，**不把原著文字、人物名字或设定作为参数值复制**：

- 《仙逆》的原著情节明确同时包含时间改变的修炼空间、限制每天进入次数、每次持续时长，以及外界时长与累计实修时长不同。**局部时间倍率、进入额度、一次进入的持续限制、实修累积**必须独立；不能用单个“十倍”直接计算一年修炼或身体增长年龄。
- 《玄鉴仙族》有明示镜内不存在异常时间流速的叙述，与同书出现的修炼资质/效率差异不同。**修炼速度不能误当时间流速**；否定或未知的流速证据不能被模型自动变成整数倍率。
- 《武动乾坤》展示短时修炼效果可能被拿来同较长外界修炼比较，这是**效果/效率对比**，不证明人物物理上多经历了数月。
- 《求魔》存在名义周期遇到提前发生的特例，**周期并非剧情必然事件**；《玄鉴仙族》的寿数描述是可能的寿命规则，不能直接推断某一人物的死亡日期。
- 不同小说中的纪元/上古年代及意念世界主观经历缺乏统一小时换算。**不推算缺失时差，不把“仿佛过了百年”当作身体必然衰老百年。**

## 3. 本轮 V3 开发文件

- `.agents/skills/xianxia-time-rule/scripts/time_parameters_v3.py` 定义**18个可独立表达的时间字段**，按原始编码/源文本边界索引提取候选；保留原文位置、单位、近似程度、否定证据、未知状态。抽取的语义结果仍**默认未审核**。
- 新增独立 `frame_access_schedule`（空间使用次数/每次持续限制）与 `actor_biological_aging_rate`（身体增长与主观经历分离）。`admit_frame_visit` 可拒绝一天内超过该世界给定次数的进入，但**绝不自动凭额度获得修炼小时**；`do_not_infer_aging_from_cultivation` 在缺少原著年龄证据时返回 UNKNOWN。
- `tests/test_wf_xianxia_time_v3_source_parameters.py`：跨 UTF-8/GB18030 精确偏移，区分练功收益/真实时间变化、纯文本纪元、章前材料、近似年数、否定时间流速。
- `tests/test_wf_xianxia_time_v3_original_access.py`：验证3次/日上限拦截第4次进入，并阻止“修炼一年”自动推出“身体老了一年”等错误。**3次/日仅是特定原著局部空间的观察值，不是通用仙侠规则。**

## 4. 完整训练的未达门槛

18项时间含义已有覆盖样本，但**6项只有一条**手工阅读证据，其余大多也很稀疏；尚无独立第二读者给出金标准，也未建立逐章节人物-空间-事件的真实时间轨迹；十本书学习、三本书留出测试的时间表达分类仅46.4%。**任何“18项都已完成训练、参数已还原整个世界时间、小说质量提升”的说法都不成立。**

需要在下一轮真正完成而不是继续增加框架：
1. 原著长篇时间证据逐章节对齐：每项独立参数至少要有多部作品支持、正例/反例、明确未知和不确定性；不允许为了填满槽位编造值。
2. 将不同人物的连续叙述、修炼、休息、等待、空间切换与历史纪元编成真实原著事件账，再做独立解码检查；目前18个参数的候选检索不能替代这一工作。
3. 用完全留出的原著章节验证事实、单位、事件时间顺序、寿数及突破因果，错误率未满足阈值前不写 WF 的正式 Author/CANON。
4. 只有完成原著时间模型的验证，再用随机玄幻人物测试“规则确实影响故事”；不再以程序单测代替训练。
