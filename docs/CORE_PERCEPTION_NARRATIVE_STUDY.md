# WriterForge 文学训练核心：人物感知因果 × 作者呈现选择（设计规范，尚未完成模型训练）

> 本规范落实一个核心目标：解释“此人为何在此刻这样看待世界”，并检验“文本为何通过这些信息与叙述手段让读者这样认识他”。不可把来源词汇标签、SQLite 结构入库或模型写的漂亮分析当成理解成功。

## 1. 必须严格分开的四种现实

1. **故事世界事实**：在对应叙事时刻已经发生的事；区分世界实际情况与角色误信的事情。
2. **人物可得信息 / 主观认识**：人物看到、听到、记起、误解、期待、恐惧什么；这不等同于客观事件。
3. **叙述者/文本呈现**：叙述焦点、能被读者看到的细节、隐去的证据、叙述时间顺序、语言选择；不能把叙述者与真实作者等同。
4. **读者在当前节点可能形成的推断**：在只看过当下文本的条件下，能合理推知什么、期待什么，以及后文如何修订。实际读者反应须由独立读者提供，模型预测只能标注 `model_reader_hypothesis`。

由文本写法推测作者的**可能叙事功能**，不能伪称拥有作者的私有心理/写作动机。至少保留替代解释和可反驳证据。

## 2. 多尺度拆分，不以句号代替场景

用现有 **原文 SHA256 + 章/卷来源定位** 作为唯一可追溯底层。八轨（情节、物品、人物、环境、时间、地点、感官、情绪）仍保留作来源检索视图，**不能充当文学理解结果**。

| 尺度 | 切分依据 | 学习任务 |
| --- | --- | --- |
| 原文证据 span | 原始字节/解码定位、连续引文 hash；保留上下句 | 哪些词句确实存在，叙述者把注意力放在哪里 |
| **感知事件** | 某人物接收到刺激、形成解释或因新信息修正认知 | 人物注意、漏看、误解、记忆、身体反应的因果 |
| **行动决策单元** | 人物有目的、阻力、信息、选择、行动、后果 | 为什么选择这一行动，是否存在当时可行替代方案 |
| **叙事节拍** | 一个局部信息释放、视角转移、冲突变化或读者预期变化 | 为什么在这里展示/延迟/遮蔽/重复某个细节 |
| **场景** | 相对连贯的时间、地点、参与者、冲突；场景可跨多段 | 视角/感知/决策/作者选择如何形成整体效果 |
| **跨场景关系** | 某个误解、承诺、印象、价值观在后文得到回应 | 从人物长期经历解释局部反应；检验伏笔、反转和成长 |
| **整书模型** | 事件时间线、人物认知演变、叙述习惯与变体 | 哪些机制稳定出现，哪些只是一次性的情节写法 |

一个句子可能同时参与两个感知事件；一个场景可能含多个人物。存储使用 **引用与关联图**，不要按类别复制整段原文。无法划分的边界标为待复核，不强行把每句塞进唯一分类。

## 3. 人物感知的因果链

针对一个被明确锚定的时间点和 POV 人物，建立暂定结构：

`前史/习惯 -> 当下目标/代价 -> 可得信息 -> 感官刺激 -> 注意筛选 -> 主观解释 -> 情绪/生理/价值冲突 -> 决策或克制 -> 新后果 -> 下一时刻的认知变化`

逐项追问：

- **看得见什么？** 角色处于何处、与目标距离、光线与遮挡，是否实际在场？避免全知式脑补。
- **为何偏偏看到它？** 当下目的、职业经验、创伤、欲望、身份、恐惧，哪个有文本证据？仅凭职业刻板印象不算。
- **他相信什么？** 把事实与人物信念分开；记录旧信念来自何时、是否过时、谁告诉他的。
- **他不知道/误会什么？** 不得把读者后见的揭示倒灌给人物。人物在 t 时刻的知识集以当时可见证据固定。
- **这个感知导致了什么？** 是否真的改变了注意、说话、行动、关系或风险？若没变，分析可能是氛围/铺垫，不编造决策。
- **何时会更新？** 后续一段、一章或数卷后，是否有新的事件推翻或强化旧认识。

将每个解释分三层：`explicit`（原文明示）、`strong_inference`（多处来源支持）、`hypothesis`（仅是竞争性的可能解释）。同时记录 `unknown`，防止伪确定性。

## 4. 作者呈现选择：研究可观察写法，而非推心

在相同事件之下分析文本确实做过哪些取舍：

- **叙事焦点**：以谁的有限知识观察？读者比人物知道得多还是少？
- **信息释放**：先呈现异常再给原因，还是先告诉原因？伏笔/悬念/反讽有什么可证实效果？
- **细节筛选**：为何选择鞋底、门闩、气味而非全面物品清单？它帮助说明什么关系/风险/情绪？
- **叙述距离与语言**：贴近内心、动作外显、自由间接表达、概括性叙述、对话、沉默分别有什么后果？
- **节奏和对比**：停顿、重复、突兀中断、环境与心理反差、前后照应。
- **叙述者可靠性**：是否有故意隐瞒、视角盲点、误判；不可自动等同作者真实意图。

每一个“作者为何这样写”的结论必须同时满足：
(1) 精确来源锚点；(2) 同场景前后文本；(3) 不少于一项替代假设；(4) **文本层面的反事实改写预测**（替换叙述顺序或焦点会损失什么，而不是单纯说“文笔更好”）；(5) 尽可能由后文和独立评审检验。
不能证实只能写“可能是……”，不可提炼成稳定技能。

## 5. 阅读顺序（严格防剧透）

1. **定位并固定 source**：私人 R2 已验证 SHA；卷章/句位置齐备；不让整个私有文本进入公开仓库、Actions 输出或模型聊天。
2. **首次阅读锁定**：只读场景前半和角色截至当下可得知识，保存人物理解、读者预测、疑问及不确定度；持久化后才能继续。
3. **局部揭示**：读到接下来的描写，记录哪些预测被证实/推翻、哪些仍未知；不准回写旧预测。
4. **人物因果复盘**：用前文与后文的证据校正人物信念与行动理由；区分解释/推断/臆造。
5. **叙事选择比较**：保持客观事件不变，试写或评价不同视角、提前揭示、删除细节；比较读者能合理知道的内容，不是只打分词句华丽度。
6. **远处回看**：在相关后续章节出现后补一条新的解释版本，留下之前错误记录和时间戳；不追溯覆盖。
7. **独立复核**：由与产生假设不同的评审器/真人核对来源，标记 `supported / contradicted / underdetermined`，不能让模型给自己发合格证。
8. **迁移实验**：以**未见过的全新人物处境**生成原创片段，与同模型无 WriterForge 基线作盲测；场景目标一致、无复制原著，不得把原文剧情混入稿件。

## 6. 两条主线的数据记录

### A. 人物认知状态 `CharacterPerception`

`{work_id, source_sha256, character_id, scene_id, at_event, knowledge_before_refs, accessible_signal_refs, attention_refs, belief_before, belief_after, motive_candidates, uncertainty, emotional_cues_refs, behavior_refs, consequences_refs, evidence_level, competing_explanations, reviewer_status}`

字段可以 `unknown`；不允许填空式编造。尤其 `knowledge_before_refs` 必须严格限制在当前事件之前。

### B. 叙事呈现假说 `NarrativeChoice`

`{work_id, source_sha256, scene_id, narrator_focalizer, visible_to_reader_refs, withheld_information_refs, ordering_operation, detail_selection_refs, rhetorical_operation, possible_functions, counterfactual_operation, predicted_reader_difference, later_resolution_refs, competing_hypotheses, evidence_level, reviewer_status}`

每项以 ID 引用原文证据，不复制整本或一大段著作。分析试验的短引用只在受控的私有 SQLite/R2 存储里保留。公有 CI 只输出数量、状态、哈希与来源行号。

## 7. 示例（完全虚构，不来自原著）

场景：一名守门人听见雨中有人敲门，却没有看那人的脸，先低头看脚上有没有泥；他看见鞋尖干净，悄悄将门闩推回去。

**错误式八轨学习**：环境=雨；人物=守门人；动作=推门闩；情绪=警惕。此标签不能解释因果。

**候选人物解释**：他可能认为人在雨中走来鞋上理应有泥，干净鞋尖说明来人的路径/身份与表面情况不符。必须去前文寻找他是否熟悉来访者通道或有没有刚下过雨的证据；否则仅为 `hypothesis`。

**文本写法解释**：作者省略来人姓名和脸，让读者与守门人共同把注意力集中于鞋尖；如果先交代来人的真正身份，读者关注点将由“猜测危险”转成“等待守门人发现危险”。这是待盲评的反事实假说。

**怎样验证**：让两个版本面对不知道后文的独立读者，看他们是否作出不同预测。不能仅凭模型解释中出现“悬念”二字就判为学习成功。

## 8. 质量门槛与失败保存

- **来源真实**：原文 SHA、精确定位、视角知识上限必须通过；不通过则整个样本 `blocked`。
- **分层解释**：现实事实、角色信念、叙述者呈现、读者推测不能混用。
- **证据充分**：每个关键推论要能找到可逐字核验的证据；没有证据则保留 unknown/hypothesis。
- **反事实有效**：说明**改写后的特定认知差异**，不是“情感不够细腻”空话。
- **跨篇迁移**：源外生成有效，而且优于无 Skill 的同模型盲测；否则不得晋级。
- **失败不丢失**：错误、被驳回解释、审阅者不同意和重试后结果全部保存。
- **能力计算边界**：一次只读一书、章节增量事务、场景窗口有上限、错误重试有上限、只加载所需来源关联；避开全文全量同时入内存的设计。

## 9. 与现有仓库的对应关系及真实状态

当前 `source_study._unitize` 已产生章/段/句结构，但存在固定 240 字切块，**未形成可靠的原文 offset/场景级连续定位**；`_structural_analysis` 仅按词汇信号生成八轨分类；`modern_source.study_modern_source` 完成的是 SQLite **确定性结构学习**。

`scene_learning.SceneLiteraryStudy` 已有“首次阅读锁定 → 后文揭示 → 来源引文核对 → 解释与反事实 → 待审”雏形，但仅已有人工设定的《红楼梦》第三回试点场景，不能称为对全部小说逐场景文学理解；用户的 9 本私人现代原著里，当前《完美世界》《遮天》《莽荒纪》已完成独立 R2 SQLite 结构学习验收，并**没有上述文学语义理解的独立合格报告**。

### 下一实现阶段只针对一书

选择已结构入库的《莽荒纪》，不开新 Skill、不开始大规模写作考试。先补 **引用真实位置+有限叙事窗口+角色/读者知识隔离**，以少量真实场景验证人物感知假设及叙述选择；如没有可访问的真实模型和独立评审，则输出 `source_prepared / review_blocked`，不作文学能力成功声明。

**最终目标不是记住作者句子，而是把不同故事里“人物认知如何导致行动、作者信息编排如何导致读者体验”的可迁移规律学出来，并在完全陌生的人物与冲突中证明有效。**
