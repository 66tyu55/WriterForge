# WriterForge 世界生态 Skill 0.1｜单回合自我选择与场外世界运转（2026-11-18）

**实验层：SHADOW，仅供分支验证；不是文学完成度、小说盲评、意识或大模型独立思考证据。**

## 改变了什么

上一轮已在 `experiment/wf-light-continuity-over-sevenskill-20261118` 完成轻量连续性合成检查和《水牌》原创示范。用户进一步明确：**每个人都有自己的想法、生活和故事；这些思考甚至行为可以完全不写给读者。** 不能把小说变成“所有 NPC 都等主角触发”。也不能把每个人都塑造成专门替作者安排伏笔的角色。

本轮不是新增文学评分体系，也不是用七个参数 Skill 重建模型文笔，而是做一个**可运行、可替换人物决策器的微型生态执行内核**：

- `actor_view` 提供**仅限人物自身**能接触的信息。其他 NPC 的动机、信念、资源及离场事件不送入输入；消息 `TELL` 只是听说，不能直接变成世界事实。
- `step` 在主角完全不行动时仍让环境/其他人活动。同一轮先收集所有人物的决定，再依可行性结算，避免前一人的秘事无故成为后一人“已知”。
- `WAIT` 允许零痕迹；失败行为不被编造成成功，**但行动失败后内心仍可以改变计划**；资源不能凭空生成，涨水阻路不自动消失。
- `OFFER` 不是自动赠与，接收者下一轮可以 `ACCEPT` 或 `DECLINE`。这很重要，因为旁人也有尊严、需要、戒心，不是主角的附属物。
- `reader_slice` 默认为零条呈现，且明确阻止当前角色读到没有机会见到的场外行动。任何可见事件也只是“可能看见”，不会强迫写出。

## 实际运行结果

在本地纯 Python 环境执行：

```bash
python -m unittest discover -s tests -p test_wf_world_ecology_shadow.py -v
python .agents/skills/wf-world-ecology/scripts/ecology_demo.py
```

**13/13 合成接口测试通过；零付费、零新模型请求、零正式写入。** 测试覆盖：私有知识隔离、场外人物独立动作、主角目标变化不使NPC命运自动改变、行动失败与目标变化的区分、路况约束、承诺必须获对方接受、拒绝权、物资守恒、传闻与事实、同一回合信息不穿越、伪造身份/库存/签名检查。

可复现实例（全部测试者人工写定，非真实模型自主决策）：

| 维度 | 两轮结果 |
|---|---|
| 人物 | 4 人，阿芷、庄二、渡娘、巡渠吏 |
| 主角行动 | 0 次；世界没有停机 |
| 水位 | 0 → 1 → 3 |
| 米商庄二 | 自己收好2份米粮，并消耗劳力 |
| 渡娘 | 第一轮成功抵达西岸，第二轮因水位封路无法回来 |
| 渡娘的想法 | 第二轮仍能改变内部计划，不能把未成行记作已到达 |
| 当前读者自动获得的场外痕迹 | **0**；只有作者主动选择且视角允许的痕迹才可能写出 |
| 生态世界实变事件（包含雨水变化） | 5 条 |

这只是一个最小实验：水位由场景输入，不是气象智能；4个人的 `chooser()` 是预先编写的人工策略，而非4个真正隔离的强模型调用。**13/13是机制自洽测试，不能说 WF 学会了“真实思考”或文字已改善。** SHA用于完整性检查，不是防恶意作者伪造的安全签名。现在也没有对社会制度、货物接受/撤回的全部现实情况作模拟。

## 与正式 WF 的连接点与下一关

现有 `writerforge/narrative_core.py` 已提供人物意图、关系、认知/线索的唯一经审核长期存储；V114/V116/V117负责文字中可证的时间、物件与连续性。**生态 Skill 不建立并行长期数据库**。只有未来作者确认某事已写入小说，且能给出原文锚点，才允许由旧 Canon/`advance_graph` 管道收纳；现在绝不自动推广模拟结果。

**下一关才是真正检验心机、生活与故事是否自行生长：** 同一处境，实际调用具备独立视角输入的模型为若干人物分别作出原始决策；记录每次原始请求/回复、成本、是否失败，并屏蔽其他人物秘密；把结算后的读者有限所见交给**同一个作者模型**写一段正文，与没有生态 Skill 的裸模型同题比较。必须查“隐秘想法是否影响真实行动”“有没有强行制造线索”“是否破坏文笔”三项。人物可不行动，也可一生未与主角碰面。

本轮不调用模型，不接正式 WF 作者，不合并 main，不部署 Railway，不写 R2、Xuehai 或 Canon。失败仍保留，不得为了测试好看强迫角色成功。
