# WriterForge V43｜“经验能否真的改变执行行为？”真实入口对照与价值判定（2026-10-17）

## 预先约定的三层验收

1. **接线**：已有文学失败经验必须通过实际 WriterForge WRITE 生产入口生效，而不只改提示词。
2. **安全与纠错**：错误证据要被拒绝；不同题材不必激活；独立负面反馈要能停用候选；历史文本不得修改。此处“独立反馈”是调用者声明，没有经过服务端身份认证，**不能当文学真值**。
3. **文学进步**：相同宿主+真实新创作题，对照有/无经验，经过盲读评审，才能判是否让作品更好。**本轮没有运行文学AB，因此这一层不通过。**

## 真正修改的生产代码

- 改的是 writerforge/verified_flow.py 中实际使用的 VerifiedWritingFlow.prepare 与 save_candidate，并未另外造一个没人调用的技能。
- 新增 writerforge/experience_executor.py 保存基于 V38 已存在负面证据 SHA 的 L2实验候选（不是“已证实的手法”），**显式项目级opt-in** 才会生效。没有批准时正式写作行为原样保留。
- 在关注 setup_payoff 的创作中，候选先检查真实 prewrite 人物知识、未知、线索身份、行为及相依因果、后续揭示目标；**没有这份计划就阻断实际 prepare**，不是补一句“注意伏笔”提示词。传入计划会按 SHA 不可变入现有WF SQLite，随后才能完成创作packet。
- 候选在 WRITE 后，save_candidate 必须得到该篇真实正文独一无二且时间有序的观察/行动/后果/揭示四段精确引文；漏项、伪造、时序反转一律不能归档候选。主稿不会因此自动获得文学认可。
- 查询WF已有 causal_events 持久故事状态：如果某 clue_id 此前被记录为**confirmed payoff**，拒绝再次把同一 identity 当新的 setup（V38 R39类事件角色冲突）；但有争议的review_status=disputed不冒充已确认文学事实，不做“必须前50%铺垫”之类绝对阈值。
- 同项目不同真实场景的两条 HARMED 反馈会把实验候选自动暂停，恢复原无经验路径；永不自动晋级。评审字段是声明性来源，不具备独立评审密码学证明，不允许计文学胜率。最多128条预写计划；故事事件扫描上限128，避免无限增长。
- 未启用实验时保存/写作接口向后兼容。实验仅影响显式启用的项目与适配场景，未改V35–V42、既有文学经验或者公开正式Skill。

## 真实测试证据：结构与过程有效

最新独立专项 Actions [#39035116954](https://github.com/66tyu55/WriterForge/actions/runs/39035116954) success（早期11项含新负例；最终版本以最新CI为准），测试使用真实 WriterForgeDB、OriginalStudy 原著文字结构入库、Published Xuehai、VerifiedWritingFlow.prepare 与 save_candidate，**没有伪造另一个入口**。现有V23真实生产路径10项兼容测试也通过。0语言模型调用，无API消费，0人类文学评价。

| 对照 | 原入口/无经验 | 开启V38候选经验 |
| --- | --- | --- |
| 空白伏笔写前知识链 | 允许生成prompt | 提前BLOCK |
| 给出有效结构链 | 直接生成prompt | SHA冻结链再允许生成prompt |
| 写后缺正文引文 | 可保存候选 | BLOCK |
| 伪造或时序倒置引文 | 通用路径不检查 | BLOCK |
| 已确认回收的同一clue冒充新铺垫 | 通用路径未查角色 | BLOCK |
| 外部审评有争议而非确认 | 未管 | 保留不确定性，不强判失败 |
| 不包含伏笔的场景 | 可执行 | 可执行，不激活L2 |
| 两个不同场景的负面反馈 | 无对应规则 | 实验规则暂停，恢复默认路径 |

这些全部是合成叙事状态与原仓库实际写作执行的工程对照；它们**不证明**读者更喜欢加规则后的作品，更不证明文学策略L2正确。根据V38原始交接，R39与R43实际的文学角色尚有独立模型争议，不能把其R2原文无法访问的语义争论偷改成“confirmed”来赚一次胜利。

## 是否真正有用？诚实判定

- **有工程用途**：历史负面经验现在会改变WF的生产执行、禁止特定错误状态、绑定创作证据并能安全回退。存在可重复的反例测试，不是只存JSON。
- **可能有文学负作用**：强制补知识账簿可能加重准备成本、打断创作，也可能让模型填写看似合理但无真实因果的结构，甚至使风格机械；当前并不能排除。
- **文学有效性未通过**：未完成同宿主、盲测、实际完整小说比较和多题材稳定改善；不能说WF“已经学会伏笔”或“自我优化了文学质量”。
- **迭代能力初步具备**：候选能被激活、约束执行、接收反馈、撤销失效；但尚无在独立文学反馈下自动产生更优秀新策略的确凿证据。反馈操作目前基于声明性独立审阅，而非可信签名身份；正式晋级仍需独立资格和可回放证据。

**结论：证明经验有实际执行权，尚未证明写作质量受益。继续保留隔离Draft PR、第一课程NOT_PASSED、第二LOCKED。若以后不能在新小说中稳定提升质量，就应该撤销这层策略，而不是为了“有用”强行保存它。**
