# WriterForge V28 · 随机原创小说第一章三组 A/B 文学实验（2026-10-17）

**本轮不是抽三段原著反复作同一个故事**。用户指定首章结构：陌生地点→夜间传说→少年受意外困于安全聚落外→诡异渐增→逃亡、慌乱→某个地点的因果/认知转折→有具体悬念的第一章末尾。实验先独立创作六套完整故事设定，再以固定 `SHA256(seed:scenario_id)` 取前三个，避免模型分数出来后挑好题。

## 预注册三道原创首章题

1. `copper_valley`：北境矿谷，夜间停工井中传来敲击计数。少年运工具时断索，错过矿营封门；异声升级，在逃亡中坠进废测绘室，再以亲见可回查线索产生转折与悬念。
2. `cedar_night`：古杉林与守林石塔，夜风似能刻失踪者姓名。采药少年损坏路标错失归村路线，慌乱逃到旧观火塔，真相只能由可见事实支持，结尾留下危险。
3. `black_tide`：黑沙盐湾，雾灯模仿亲人之声。少年送盐账时潮水冲毁归村木栈道，涨潮阻路，误判后逃到废弃潮汐钟房，通过先前线索获得新认知却非全知。

六题总体来源、选中身份和各题 SHA 见 `writerforge/random_original_openings.py`。选中三个是完整、手工独立创作的约束，不是随机拼接几个关键词。每篇只要求完成**独立的第一章**，不是同一部长篇的第1–3章。保留作者自主选择人物与具体异常因果的空间；不得将提纲机械罗列成正文。

## 实验控制

- 学习来源**固定**为私有 R2 《武动乾坤》SHA `86a2fd859b424efe0500b4b36713ea8b05d551140650904ffc2ae02eb244ed28`，实际提取第3章首个 **1132 字符**连续窗口。来源首段 SHA `96b6363d40be7b99d5635af1346da0c04e44556fc06e32d1aab04e419e4942fa`，后续相邻窗口 SHA `9ddcccf76a3f63d8036355c006ee20c976dacb1dd6ff250ef921f47e9221ac8e`。第3章只是隔离诊断来源，不代表第1窗口课程过关，第二课程窗口保持 LOCKED。
- 三个任务互相独立，共同的 Planner/Critic `deepseek-v4-flash-0731`、Writer `glm-5.3`。原著正文与人物剧情只进入 Planner；Writer只获得公开原创题目以及最多两项宿主白名单操作；Critic只见同题匿名A/B原创新稿和公平评分协议。
- 同一原创题的无技能和WF两组保持中立共同的首章篇幅目标1070字符（默认共同误差至多8%的指导语，不等于长度验证闸门）；如果稿长差超过15%，可在共享token预算内**两组各同等改写一次**，绝不能只改 WF 或截断原稿。后验长度差如仍超过15%，**这组只有失败证据，没有文学分**。
- 每个任务共享最多7次真实 API 和50,000预约输出Token硬预算；角色预留 Planner5500 / Writer7500 / Critic7000，4个 Writer 调用最大预算 42500，给传输异常留下有限余地。GLM Writer显式低推理模式，已有独立的无原文真实网关探针通过；这些是**新实验协议**，不能与历史 V5/V6 单因果等同。
- 评审五项：人物感知、因果、信息释放、连续、语言。分数保留原始五维；用户要求的无技能30显示锚点只对两组同移分数，不能伪称模型真正认为无技能只有30分。单次评审非独立真人裁决、非模型权重训练或已完成文学核心迁移。
- 仅持久存私有R2 SHA指纹、简短脱敏文学观察、客观字数和分项、宿主机制ID、模型用量及禁止晋级标记。全文原著和A/B草稿在运行容器内为临时数据，不向公开仓库或日志写全文。若要真人对同稿逐字复评，需要另立隐私保护的草稿留存协议，此次不谎称已经做到。
- 触发一次性工作流：[`V28 three randomized original first chapter A-B real one-shot`](https://github.com/66tyu55/WriterForge/actions/runs/39003570775)，矩阵 slot 0/1/2，另有无模型R2汇总。任何一组失败都不得补造成低分，也不能为了达成三组正例任意换题。
