## 关键局限，不能藏

- 同一个聊天宿主已经看过原著才写无经验稿，存在训练材料串入基线记忆的污染；尽管A提示词没有经验文字，模型上下文不可真正隔离。
- 所有run都按基线在前、经验在后，存在第二次写同题的修订与顺序偏差；经验稿还普遍比基线长67—159字，可能带来长度优势。
- 三个run阅读同一来源章节，学习能力和跨作品可迁移性没有独立新来源多样性。
- `model_id` 是由聊天脚本声明的同一GPT-6，不包含第三方签名或模型服务响应追踪；相同模型身份无法以密码学证明。
- 复盘由同一宿主生成，仅有主观缺点判断，不能充当评委。
- 所有正文均为`accepted=false`的候选稿，不是经作者批准的正式出版文本。
