# WF 七 Skill 协同训练预注册方案（2026-11-14）

**性质：SHADOW / 方案与隔离接口已实施，真实协同训练和文学准确率尚未验证。**

这份方案严格对应用户的意思：**七个 Skill 各自训练、拥有自己完整独立的参数；一起阅读同一原著、互相交流证据、提高各自的正确率；断开交流以后独立能力仍必须成立。** 不合并参数、不合并训练成果、不做第二份世界大库。

## 1. 参加者与职责

现有四项：
- 时间 `xianxia-time-rule`：世界时间、人物经历、闭关、寿元、时限、参考系；
- 空间 `wf-space-topology`：地点、房间、方向、路线、门禁、空间连续性；
- 人物认知 `wf-character-epistemics`：身份、知道什么、误信什么、选择、信息来源；
- 世界因果 `wf-world-logic`：制度、资源、行动许可、代价、可变因果。

新增三个独立 Skill（仅建立研究定义，未训练）：
- `wf-personality-affect`：长期性格与短期情绪，互相影响但不可等同；
- `wf-appearance-body`：外貌与受伤/疲劳/恢复状态，不推导未明示的年龄、寿数；
- `wf-atmosphere-prose`：场景气氛、视角、表达技法和读者感受，不当作世界物理规则。

**两条尚未合并的实验线：** PR #71 是时间，PR #72 是空间/人物/世界；本分支基于 PR #72，暂以只读协议参照 PR #71 的时间参数。**七种参数的真实跨分支执行尚未发生。** 新增文件只是 SHADOW 研究协议及源文无关隔离单测。

## 2. 同一次训练的正确执行顺序

1. **共同读全篇**：在受控私有环境中，每个 Skill 能读同一段完整原著，不由总控提前摘要并删去配角、环境、情绪等信息。原始正文保留本地，原文长度、版本 SHA、章节范围固定。
2. **先独立**：各 Skill 分开上下文，独立提出自己负责的候选参数及原文证据；旧参数可保留版本、不能以新版本重写过去。各自错误照录。
3. **后协作**：各 Skill 仅发送事件 ID + 证据位置 + 临时分析意见。收到意见的一方必须**自己回读原文、自己决定是否修订自己的参数**。其他 Skill 没有改写权限；收到的是疑点，不是答案。
4. **彻底断开**：屏蔽其他 Skill 的意见，在未见过的章节独立答题，检查是否真的能复原本领域的事件约束，而不是依赖别人的推断。
5. **再次组合**：只读加载各自参数，检查跨领域故事约束、相互矛盾、错误传播。拆开再装回去，独立参数和版本不丢失。

允许情绪 Skill 质疑人物 Skill 的“动机已知”，外貌 Skill 提供“脸色发白”的证据，但**脸色白不能自动变成害怕、情绪悲伤不能直接证明世界正在下雨、时间过去三小时不能证明人物已到达另一座城**。

## 3. 对照实验：四种训练臂 + 拆开复测

| 训练臂 | 学习 Skill | 互相提供线索 | 比较目的 |
|---|---|---|---|
| A4 | 现有4项 | 无 | 原来的独立基线 |
| B4 | 同样4项 | 有 | 四项协作是否改善原4项 |
| A7 | 全7项 | 无 | 加入新领域但不互相影响时的表现 |
| B7 | 全7项 | 有 | 七项协作是否改善各自参数 |
| C7 | B7学得的各 Skill 单独保留 | 禁止 | **断开后能否保持增益** |
| D7 | 再次组合C7的参数 | 只读 | 关联正确率及相互污染 |

A4/B4、A7/B7 采用相同原著、相同基础模型、相同每 Skill 调用次数和参数版本初态；训练臂必须用**相互隔离的会话**，B不能看到A的答案。B组的交流内容也增加 token，应设单次交流限额并真实记录总 token、耗时和模型调用。七项比四项贵是事实，不能用更多调用产生的效果宣称“纯协作收益”。

为防止再次出现运行时间过长或异常检测，**只预注册，不立即发起模型调用**。先针对一段短的连续原著做1轮，出现大量失败则停止；只有第一轮有可靠初步收益再扩到已约定的两部原著、每部连续5章，后续2章留出。没有真实来源冻结前，书名和章节尚不当成已封存测试。

## 4. 核心验收：准确、迁移、时间成本

- **独立准确率**：B7训练后C7独立输出，对比A7在相同留出原著的准确率。若独立能力下降，则不算成功。
- **协同增益**：B7相对于A7在本领域证据正确率、漏项、因果方向、未知保留上的变化；B4相对A4控制新增3项本身的影响。
- **参数完整性**：每个 owner 版本历史可精确往返，跨 Skill 无法直接改写；同一事件中的冲突不被强行合并成一个虚构事实。
- **错误传播**：主动放入一条来源不足的错误线索，观察能否被收件 Skill 拒绝，不能扩大成7个 Skill 的共同幻觉。
- **场景复原**：每个 Skill 先单独解释原著事件，再联合解释；比较对人物行动、空间许可、时间耗费、气氛与身体变化的归属是否正确。**不要求预测作者未来随意安排的情节**。
- **成本**：逐臂记录模型调用、输入/输出 token、CPU/壁钟耗时、失败重试数（默认0），按“额外准确证据/额外费用”判断7项协作是否值得。

只有独立读者对原著进行盲验，才可声明语义准确率；程序测试通过仅说明架构和数据隔离正确。所有现存反推失败记录不重算、不消除。

## 5. 当前具体实施与停线

独立协议代码：`experiments/wf7_colearning_contract.py`；
源文无关模拟隔离测试：`tests/test_wf7_skill_colearning_contract.py`。

协议目前只做参数版本所有权、证据 ID、隔离、只读协作消息、拆装一致性的验证，**不提供原著阅读、真正模型训练、跨 PR time 实时连接、因果推理，也不证明7项协作比4项准确。**

截至本文件：无新付费模型调用，无原著正文上传公开 GitHub，无自动定时任务，无正式 WF 作者/Canon/学海/R2/Railway 改动。后续执行必须单独记录真实来源版本、准入及原始模型失败。
