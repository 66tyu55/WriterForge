## 这不是要求泄露模型不可见的内部推理

系统**不能直接访问或存储隐藏的神经网络内部推理**。本实验使用真实模型主动生成的、**写作前提交**的结构化决策记录（人物/场景目标、有限知识、冲突、观察角度、手法候选、舍弃方案、选择依据和预期读者效果）。写作完成后的自述单独保存，不允许回头修改写前记录。

## 一次真实性可验证的链路

1. **00真实原文**：从已核验的私有 `xiyouji-23962` R2原著库恢复源文本 + SQLite，独立再次验证100个连续原著章节。当前试点只读第一/二回的首段**每回最多2000连续字符**；存储完整窗口文本、原著SHA、窗口SHA、绝对字符范围、章节标识于**私有R2**。不是让模型假装此时重新读100回。
2. **01读后观察**：WF内部读者模型确实收到上述窗口，输出源文中真实存在的**短连续引用**、人物知道与不知道的东西、怎样安排叙事对象/环境/声音/转折及观察本身的不确定性；引用必须在原窗口中存在。此记录先持久写入私有R2并fresh GET再进入下阶段。
3. **02抽象手法**：另一次模型调用，从已锁定的01阅读观察提炼**最多两条**适用条件、效果、失败风险、与原文情节隔离的叙事操作。保存“为什么选择／什么条件下不要用”，不把同一段原文直接塞进考生原创新稿。
4. **03公布考题，考前设计**：在第02记录真正存储后才揭示考官预选题。WF先独立形成一次带有三种场景/人物/动作/时间/感官或关系视角选择的 **显式构思决策日志**。每个选择包括使用或不用某个提炼手法、为什么、可检验的预期结果、舍弃的替代写法。**将这份完整记录单独写入R2不可变SHA；之后不得回写。**
5. **04原创新稿**：GLM5.3作者仅获得考官题目、02中提炼的非原文手法摘要、03已封存的决定，不获得《西游记》原文。保存未修改的完整正文、字符数、SHA到**私有R2**。要求目标1120字符、950–1300硬边界；超限不删除/覆盖原稿，另存修改及新SHA，修改不得伪装首稿。
6. **05写后自检**：读取R2中已存写前计划和第一稿，输出哪些计划真正体现在正文的**精确引用片段**、哪些落空、何处因果断裂、计划与实际的差别。记录独立保存，不许把后见之明覆盖考前日志。
7. **06考官审核**：比较写前03记录与实际04正文、05事后复盘，保留明确可核对的失败与依据。可加一名独立文学批评模型，但与WF写前思考区隔；模型自述与阅读效果不得等同真人客观质量验证。正式课程窗口不晋级。

## 保存与安全

每个阶段分别写到 Cloudflare **私有R2**，内容寻址、带父级SHA、严格顺序、写后重新读取校验；失败的阶段保留之前阶段原样，不进行隐藏的重写或跳级。原文为Gutenberg公版《西游记》繁体中文原著；不公开或混合其他商业原著。原创练习稿明确按本次用户请求保存到私有桶；**如果未配置客户端额外加密密钥，这不是端到端加密**，不可声称已经加密。严禁在公开GitHub Actions日志打印原著片段、创作文稿、构思内容或任何凭据，日志只输出SHA、字数、阶段和错误代码。不同阶段完整内容可从私有R2按权限审阅。

## 验收

主判据不是WF得分，而是三项可查证事实：
- WF是真的读了被哈希验证的原著窗口，还是凭空编造引用？
- 原著观察 → 写前计划 → 实际文字之间存在**可追溯一致性**，还是仅写出格式正确的理由？
- 计划中被放弃的手法与真实写作缺点能否被诚实记录，不允许写后补编构思。

即使全部技术阶段成功，也只能说**一次可观测文学学习试点跑通**；文学质量与稳定自主进化还需要多次独立题材和真人审阅。正式first window NOT_PASSED、second LOCKED。
