## 为什么要改定位方法

此前按“时间、纪元、寿命、修炼”预定18个字段，再从全本小说搜索相似词，得到11万余候选，却无法解释这些词的真实作用范围。尤其会把修炼效果等价当成局部时间倍率、把医生预报当成未来必死，把社会约定当成世界物理规则。弱监督识别曾在3部留出的28条复核样本上只对13条。

**现在从待解释的事件后果开始，而不是从字段名字开始。**

1. 先取连续章节，确定原文叙述顺序、话是谁说的、其状态是观察/陈述/预测/计划/未知。
2. 提出一个具体可反驳的问题，例如“为何3年后再次出现风险”“为什么一人获救另一人的寿元减少”“为何一年后不达标准可能改变家族身份”。
3. 只选答题所需的来源事实；每个事实记载独立角色、单位、数字原文位置、有效语境和认识状态。
4. 逐条删除候选事实，重算上述冻结问题；删除导致“有依据”变成“未知”的记作**本问题必需**，未改变的暂列“本问题未用到”，保留等待其他情节，**绝不直接删掉**。
5. 再测试刻意改错数字、错配单位、把风险写成必然死亡、把计划写成已经发生，任何一种偷换都应失败或退回 UNKNOWN。
6. 用完全没参与参数命名的后续场景作独立解码和迁移检验后，才能考虑晋级 WF 写作规则。

《元尊》事件链（匿名化）：
- 周期性病症的**3年频率**、外力压制**3年后失效**、医生所说“若状况未改变则有危险”：三个条件组合，才允许推导**3年后有条件的风险窗口**，不得说“必定死亡”。
- 每次救治声称耗费**3年寿元**、报告累计损失**36年寿元**：能在“这些损失完全由所述救治造成、报告可信”前提下计算**隐含12次**，但不能当作12次已被独立观测，更不能拿3年生命代价去推断身体老化了3年。
- 母亲余寿**不到10年**，只能保留上界，不允许补出确切死亡日期；三日后祖祭只是安排，不证明一定成功；百年不侵犯是来源陈述中的约定，不是物理壁障，期满也不保证爆发战争。

## 实际发现并修正的安全缺陷

最初即使源段锚点合法，数值仍可能被伪造（把3年填成9000年），同上一轮的“找到原文不代表理解事实”漏洞。已经先用两部原著的私有试验写出失败用例，随后加入**源文数字词绑定**（如“十”“三十六”需要和精确分数解析值一致，且不能只截取“三十六”中的“三”作为独立数字）。这仅保证数值来源匹配，不证明这个数字与人物、事件的语义绑定绝对正确，仍需复核。

- 私有两部原著实证：**13/13** 当前小试验项目通过（只是锚点/条件推导/消融/伪造测试）。
- GitHub 源文无关的合成回归：[Actions #43406721833](https://github.com/66tyu55/WriterForge/actions/runs/43406721833)，原V1 11项、V2 45项、V3 12项、新增事件发现9项，共 **77/77** PASS。
- 真实作品没有“独立第二读者金标准”，没有真实模型在未知后续章节的反推，不能给出真实训练准确率；更没形成13部原著每章的完整因果时钟。

## 保持动态、不变成死模板的原则

“参数”不是一个固定数值和类型，而是一个局部、有条件、可被推翻的**状态变化约束**。只在源书机制有证据时存在；未知就为 UNKNOWN，原著冲突就标冲突并回到源文；角色行为、意外与提前解决危机可以改变后续预测，不能为了还原前面预测强行安排结局。完整人物认知/行动动机仍是另一个独立维度，不偷塞进时间参数。
