## 1. V56 每个失败的具体性质（必须保留区分）

| 原始测试ID | 原始结果 | 已确认现象与谨慎解释 |
| --- | --- | --- |
| `guard.reader_future_spoiler` | FAIL | 读者在故事时间3被允许标记KNOWN，但所引叙述者证据事件在20；**READER缺少ACTOR的时间屏障** |
| `guard.reader_private_thought` | FAIL | 将角色私密`THINK`事件作为读者KNOWN的依据得到接受；**公开叙述/内心独白/隐私披露关系未建模** |
| `guard.knowledge_evidence_support` | FAIL | 用状态`UNKNOWN`的事实事件支持`KNOWN`主张，结构检查放行；**主张与证据状态缺乏一致性检查** |
| `continuity.cross_chapter_link` | FAIL | 第一章线索→第三章回收被`FACT_LINK_CROSS_SCENE_FORBIDDEN`拒绝；**尚无跨章节但同一作品的稳定事件身份/关系作用域** |
| `continuity.cross_chapter_state` | FAIL | 第一章已知事实在第二章查询为`UNRECORDED`；现有事实按scene隔离，**没有可信的章节之间状态继承** |
| `chronology.flashback_import` | FAIL | 先录后期事件，再补录较早发生的倒叙事件，被`FACT_BACKDATED_REVISION_FORBIDDEN`拒绝。原V54专门禁止单一时钟倒填，**这里是能力/数据模型局限，必须区分系统记录时间与故事事件时间** |
| `revision.no_fork` | FAIL | **此题测试夹具无效，不能判定分叉修订有漏洞。** 它试图在故事时间2标记KNOWN，却引用时间8的未来事件，先触发正确的`FACT_ACTOR_KNOWS_BEFORE_EVIDENCE_EVENT`，根本未到`SUPERSESSION_ALREADY_USED`检查；后续需**另造新测试**，旧红色记录保留 |
| `scale.long_record_chain` | FAIL | 同一事实68个历史主张导致`FACT_TEMPORAL_QUERY_BUDGET_EXCEEDED`；这是现有**64项固定安全上限**，能防止无限增长，却无法适用于长篇连续历史全量回放。属于扩容/分页设计问题，不是内存泄漏的证明 |

原始通过的代表项：双时轴`as_of_recorded_seq`回放；角色与读者两个已分开存储的scope能分别查询；同一时刻矛盾保留；角色提前获知未来事件被拒绝；跨**不同故事**错误连边被拒绝；`POTENTIAL_CAUSE`保持未经验证；图边方向保留；索引`index_witness`不可伪装角色/读者知识；关系边/知识记录篡改检测；已有主张可关闭重启后恢复。以上只证明结构行为，不等于小说语义能力。
