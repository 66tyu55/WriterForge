# WF 人物生态真实模型第一轮｜独立 NPC 决策 + 正文 A/B（2026-11-18）

**试验地位**：用户同意“可以”，限定尝试真实模型独立思考；本分支仅 SHADOW，不启用正式 WF，不覆写任何原著和 Xuehai。对应实验脚本 `experiments/wf_living_ecology_real_ab_once_20261118.py`。

## 为什么是这个试验

原先人物 Skill 有私有状态和“事件可见”的合成接口，但事件由人工写死。生态能否自然，首先需要**真正运行彼此隔离的角色决策调用**，而不是把同一作者的全知解释硬塞给所有人。读者不需要知道所有人的私心；一个角色完全可以因生活琐事不行动、甚至永远不回到主线。

## 冻结设计

- 公共世界：山雨三天，河上涨，旧水牌是否准确未知；小镇茶棚、渡口、米铺处于同一时间窗。
- 主角阿芷：修壶讨工钱，给生病的母亲抓药。
- 独立角色：茶棚掌柜（现金欠款／生意压力）、渡娘（舟路危险／亲人）、米铺庄二（粮袋防潮／本钱）。每个模型调用只获得一份属于**自己**的私有视角包，不得到其他两人的私有目标/认知，也不接受其他人之前的答复。
- 模型各自选 `WAIT` 或本人的一项小动作（每人3个非等待选项）。这是一个**有离散选项约束的先导实验**，不是无限自由行动；保留真实模型的 `private_reason` 和 `assumption` 原始可见回复。
- 外部世界只接纳冻结动作表中的即时结果，不能把“想接到亲人”改写成“已抵达西岸”，不把“准备搬粮”说成“粮食彻底获救”。主角能看到的只是后来的钱数、泊位或店铺表象；后台私心、动作代码、其它人知道的内容不流向作者。
- A：同一个强作者模型仅凭共同起点写完整自然的 800–1300 汉字场景；B：同模型、同样输出预算，另外得到真实角色动作之后，主角可能观察到的**极少客观结果**。两臂从未复用另一臂对话上下文、不得将其他角色秘密塞入 B。
- 模型：`deepseek-v4-pro-0813`（既有固定 Discovery 适配器，非新模型接入）；**意图为5个模型调用（3个NPC，2篇作者），最多8次包括重试/续写，最多预留12,500个输出 tokens**，调用与消费不是同一概念，按适配器实际统计。
- 每次调用分别留可见模型结果、请求体（无密钥）、返回体与 SHA；作者两篇未采纳的原创正文只存短期实验工件、不写 Canon/R2，保留长度对比与可能因额外上下文产生的费用偏差。

## 资格约束与失败

1. 先运行 offline `tests/test_wf_living_ecology_real_ab_once_20261118.py`：必须证明其他角色的私有信息不串入角色调用或作者调用；`WAIT` 不产生剧情推进；非法动作拒绝；无授权不能买 API。
2. 真正付费调用只允许一次 commit-message + run_attempt=1 硬闸，不能因失败或重跑重新刷模型。没有已连接密钥就保持 FAILED_NO_MODEL_CALLS。
3. 真实模型回复无效、预算耗尽或生成中断均保存原有负证据，不“补成结果”；即使脚本成功也只是模型真实输出获得，不意味着文学优胜。
4. A/B 输入不完全相同：B 多了真正的世界可见变化，内容更丰富是合理但会混杂因素。因此**不可**把两臂的差异归因于“生态结构本身”。检验只针对：私心隔离、NPC 有无真实非主角决策，以及正文是不是明显更有编排感。
5. **一个场景、三个 NPC 远不足以证明长篇生态。** 只有后续新世界、多个时间窗口和独立读者阅读能评估长期有效性。允许 A 更自然、B 更差；不得隐瞒。
6. 此次选择清单仍可能导致动作“剧本感”；如果三位 NPC 都选戏剧性行为，不得擅自改为“他们自己想的”，要记录选择偏差，下一轮可按失败结果重设计。

**禁止**：换主角性格后强行重放作者想要的剧情；把人心的秘密变成作者可见提示；每个人安排伏笔；强迫所有后台动作都留下读者能识别的线索；改正式 WriterForge 写作入口、Xuehai、R2、Canon、主仓或 Railway。
