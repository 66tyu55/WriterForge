# WF 原著时间参数：自主提出与冻结后续章节的实验（2026-11-13）

## 为什么测试这个

上一轮是 GPT 人工列事件问题和参数，代码删除事实后再计算是否变 UNKNOWN。这个结果只说明**人工提出的问题**对现有证据敏感，不意味着 WF 具备“自己发现参数”的能力。此次将参数命名任务交给独立的本地开源模型；模型只看到匿名事件记录、不看到人工预注册标准或后续原文。

## 训练/验证材料及隔离

- 新样本：私有原著《仙逆》的连续第 15—17 章，共 6092 个源文本字符；**21 处原文证据锚点**，GB18030 原书版本严格校验来源 SHA 和每个锚点所在字节范围。
- 经过助手人工归纳形成 **11 条匿名观察**：人物相对时刻、夜间修炼、环境效率、场所禁令、劳动制度变动、人物消息差异、资源交换承诺、未证实的作用机制。只让模型看到这 11 条观察，不给原书名、人名、逐字原文或证据位移。
- 测试材料：第 18—19 章完全封闭，原文字节 SHA：`54af7e4ed0dc0bc35cb3c237d68aac95d130b7050ca6888679e4afc6f3c90644`。哈希在模型执行前锁定；**下一章的具体剧情不能凭预训练预知声称预测成功**。
- 预先冻结的私有评分规则有 9 条真实来源机制，SHA：`0ea5eaf8a35ee1bb62d8e5a9d80e55d297831b37a937ca3bb629bc9cbbb61aad`。来源由同一个助手复核，**不是独立第二读者金标准**；只用于初步研究。
- 模型：此前已可在 GitHub Actions 运行的 SHA 钉死的 Qwen2.5-3B-Instruct Q4_K_M，温度 0、种子 20261113、每组最高 1600 token。两次本地实推理，无新付费 API，原始输出不重试。

## 两组严格分离

- `direct`：模型直接基于当前匿名事实提出自认为必要的时间约束，不事先指定18个类别。
- `event_first`：同一模型先列目前事件与未来反事实问题，反问没有什么条件会无法判断，再提出最少需要的时间变量。
- 两组都用**完全相同的 11 条匿名观察**。区别仅在任务指令，预注册标准一致。不同提示长度使其结果只是方法探索，**没有统计学的对照意义**。

JSON 中各候选必须明确 `owner`、`trigger`、`variable`、`unit`、`update_rule`、`epistemic`、`could_change`、`failure_if_missing` 和证据观察 ID。引用观察编号只能证明有来源入口，**不能证明真实语义正确**。所有模型候选的审批状态依然是 UNVERIFIED。

## 验收关口

在收到原始模型输出后才可解封私有评分标准和下一段原著：

1. 比较真实源文可支持的9项机制中，哪一组独立提及并符合其认识边界；
2. 检查任一组是否凭空断言倍率、修炼满时间必突破、承诺已履行、人物知道隐秘、植物变化的原因已经证实；
3. 查未知后续是否暴露新的规则缺口。**真实意外和不可推断剧情不是模型错误**；只有在原有证据应可约束却丢失或反向解释时才计失败；
4. 若 event_first 没有更好地定位真实规则，或新增因果幻觉，则继续判方法未证实，不用更多规则类型或同题重试刷准确率。

**最大局限**：目前匿名事件是助手从原著整理的，模型本身还没有自主读取整章并标出全部事件；这次检验的是“从事件自动发现参数”而非“端到端全部原文建模”。成功也不等于13本原著已训练完成，更不等于学会小说创作。PR 保持 SHADOW，不写 Xuehai/R2/Canon/生产作者。
