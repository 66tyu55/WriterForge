# WriterForge 0.T — 《凡人》前两章小段解锁 × 原创《潮簿》双轨渐进验收

**2026-10-25 / 实验开发分支：** `refactor-unified-scene-delivery-audit`。本文件是实验规约，不是实验成功证书。

## 为什么做这项实验

0.T 的任务不是 WF 从文学角度代替模型判断好坏，而是 WF 让原作者 AI 在自己真实写出的原文上完成**发现—选择—局部修改—校验—回滚失效状态—重写后文**。本实验还要判别文学原著逐段阅读究竟是否改善句子、段落、人物选择和事件因果，而非只对齐模型输出格式。

历史 0.T 真实改稿因 V96 动作/后果引句重叠而失败；模拟测试证明机制行为但不能替代新的真实原作者写作闭环。旧的 `wf_source_progression_ab.py` / `wf_same_first_turn_literary_ab.py` 仅比较 WF 提示方式，不是原著可见性，不能借用旧胜负结论。

## 双轨从 0 到 1，不整章灌输

相同原创大纲：`《潮簿》`，架空海潮堤坝世界；主人公林栖为抄簿工，程满是经历过事故的测潮人。与《凡人修仙传》不共用角色、门派、物件、奇遇线或章节剧情。两组冻结相同两条 V96 片段意图，但文学语言、人物微动作、实际情节推进仍由**同一个** DeepSeek Flash 原作者分别决定。

| 变量 | A（原著隐藏） | B（渐进阅读） |
| --- | --- | --- |
| 原创大纲/角色/片段目标 | 同一份 | 同一份 |
| WF V96/V114/V116/V117/V119 与统一叙事记忆 | 相同 | 相同 |
| 模型/预算 | 同一模型、严格总调用上限 | 同一模型、严格总调用上限 |
| 第一次写作 | 只见原创大纲，写一个短场景片段 | 额外只见经 SHA256 校验的原著第一章开头约 230 字 |
| 作者回头选择 | 原作者独立选择 MOVE_ON / LOOK_BACK_NOW | 相同 |
| 改稿和源校验 | 作者自己给 V119 替换，再过 V96/V114/V117 | 相同 |
| 第二次写作 | 在真正第一段的结果之后生成新片段 | 仅新增第二章开头约 230 字阅读窗口，再写新片段 |
| 整部原著 | **绝不给模型** | **绝不给模型** |

真实私有原著必须经 `WRITERFORGE_FANREN_SOURCE_URL`（HTTPS，只读）、`WRITERFORGE_FANREN_SOURCE_SHA256` 双重校验；不能访问时**零模型调用且报告缺失**。提取的两处短小阅读窗口仅暂存动作 runner 内存，原文不进 GitHub、报告、图表、源正文或用户可下载的盲测稿。A 完全没有“原文片段/原著摘要”的模型输入；但基础模型可能在预训练时知道《凡人》，所以 A 是**没有在本轮看到原文**，不是知识完全消除的盲模。

## 真实完整修复闭环的证据门槛

1. **写作原件：** 真实 DeepSeek 输出第 1 段，留模型原始响应 SHA；不接受测试程序造的小说句子、模拟模型“成功”或静默把格式错答改为正文。
2. **原作者自主选择：** 模型自己判断保留还是回头。若 MOVE_ON，不许把其当作真实修复。
3. **如选择回头：** 由现成 `prepare_source_repair_contract` 提供来源、前因、待核状态；模型自己决定删/改原句；`_self_edit_one_turn` 通过 V119 锁定替换、风险差异、循环阻断、至多一次同作者引句更正。无效则回滚或 HOLD，无自动润色或无限补考。
4. **真实后果：** 重新运行 V96，V114/NoveI Studio 状态 reducer，V116 新风险，V117 连贯性检查。仅在最终真实稿校验通过时才调用同一作者模型写第二段。后段不得回放删改前草稿，也不得继承已废弃的候选状态。
5. **统一记忆：** 先保存两段实际正文至本地候选文件、核对 hash，再 `record_chapter_memory` 和 `make_resume`；无新记忆主人、R2 写入或 Canon 提升。
6. **判定条件：** 出现真正被采纳的作者改稿、两个不同真实源 SHA、真实第二次创作，且 V96/V114/V117 与统一记忆签收，才称 `real_full_repair_accepted=true`。没选改、没改成、模型失败、原文取不到都明确标为未完成。

## 文学对比（不由 WF 自动打分）

每一步分解句子，报告汉字数、短句/长句频率、句长、对白占比及跨段已写事实的延续；这是可核查的描述统计，不是“好文学”的自动评分。保存原创模型两版小段匿名稿 X/Y 供独立人工盲评，人工从**句子、动作选择、代价、人物动机、节奏、叙事自然度、保留必要悬念**逐项指出证据原句；若没有人评则只能说结果待审。

一个 N=1 的 A/B 不能证明“读原著导致水平提高”，模型采样差异也会影响句子。下轮可以复制同一真实首段的 paired continuation、交换顺序并累积多组，但不能因此重复已完成的 15 章训练。

## 安全和运行范围

- 预算：一轮最多 10 次新模型请求、14,200 个预留输出 tokens；拒绝不明消耗、任何自动重试，容许失败而不是伪造通过。
- B 原文窗口不得连续照抄 30 字；必须原创，否则候选 HOLD，潜在含原文的原始回包不得上传为公开 artifact。
- 所有实验内容为未接受候选；不修改 `main`，不部署 Railway，不碰真实 Canon，不写 R2，不增加独立文学记忆或评价模型。
- 无成本测试：`python -m unittest tests.test_wf_fanren_staged_source_ab_0t -q`，完整回归由 `unified-scene-delivery-audit.yml` 负责。
- 真实运行只在指定的 **one-shot** sentinel 提交时触发 `.github/workflows/wf-fanren-staged-source-ab-0t.yml`。提交工作流本身**不触发收费模型**。
- 脚本：`experiments/wf_fanren_staged_source_ab_0t.py`。匿名结果、来源 SHA、模型回复 SHA、失败码统一在 `wf_fanren_staged_ab_0T/`；完整原著绝不在其中。
