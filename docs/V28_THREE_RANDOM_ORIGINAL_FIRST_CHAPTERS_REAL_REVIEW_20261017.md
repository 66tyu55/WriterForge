## 实验事实：三道原创题目，不是三段原著

用户给出一个自由首章骨架：地点、夜晚的传说、少年因意外不能返回安全聚落、诡异升级、惊慌逃亡、某地点的转折和具体悬念。本轮先写出六套完整、具有内部因果的原创设定，再使用提前钉住的 `SHA256(seed:ID)` 抽中 **封矿峡谷、古杉林、黑沙盐湾**，而不是把“人物/场景/物件”随机拼词。种子和每题散列见 `writerforge/random_original_openings.py`；抽样在任何模型评分之前冻结。

为了专门测**对不同写作题目的适应能力**，三组都从同一份私有原著《武动乾坤》**第3章首个连续1132字符学习窗**抽象出合法宿主机制，原著版源SHA `86a2fd859b424efe0500b4b36713ea8b05d551140650904ffc2ae02eb244ed28`，窗口SHA `96b6363d40be7b99d5635af1346da0c04e44556fc06e32d1aab04e419e4942fa`。此处是诊断取材，**不是正式课程解锁第3章**。

模型角色固定：Planner/Critic 为 `deepseek-v4-flash-0731`，Writer 为 `glm-5.3`。GLM Writer采用网关已验证的低推理参数，Writer仅获得独立原创题目与宿主预置白名单技巧；Critic只见相同题目与匿名双稿，原著正文不送Writer/Critic。两稿有相同1070字符指导目标，共享 15% 最大篇幅差距闸门。若初稿差距过大，可给两组各一次对称编辑机会；本轮三组初稿本身均通过，因此**三组修订次数都是0**。

真实付费 [Actions #39003570775](https://github.com/66tyu55/WriterForge/actions/runs/39003570775)：3个不同题目的matrix jobs均完成/success，最终私有R2只读汇总也完成/success；每题规划1/写作2/评审1，共 **12个真实模型调用**。服务商报告输入 token 分别 4769/4496/5199，总 **14,464**；输出3082/2631/3419，总 **9,132**，合计 **23,596 tokens**。预留token上限不代表实际扣款或消耗。草稿与私有原著正文未长期保存或公开传输到GitHub。

## 从失败中得到的真正改进方向

1. **原文“机制证据ID存在”≠语义适用性已证实。** Planner只受4项宿主预置文学操作约束、默认总要选1–2项，在不同题目中可能重复同一组合。这是**模型评分出现跨题材不一致的候选原因**，不是已经证明古杉林那篇到底哪里写坏；草稿正文已按原存储政策临时销毁，无法独立逐字复评。
2. **不能全局禁用或盲目强化 `GOAL+WITHHOLD`。** 两组正向和一组负向同时存在；需要给不同任务保存来源SHA、题目SHA、选中机制ID、五维分差及适用性假说，保留正反样本。
3. **不能只看三次平均+8。** 古杉林回退-7.4且五维全负是必须单独分析的具体失败。要让另一独立Critic/真人真正阅读同稿、检查“传说是否影响少年已知信息、夜晚怪异是否具有共同核心、逃亡选择是否有具体代价、转折是否能由前文线索推断”；当前没有同稿全文复核证据，这些仍是验证问题，不能假冒审稿定论。
4. **文学与技术质量要分开。** 三组A/B都通过了相对稿长闸门，没有出现上次第17章的网络/截断反复重试；但绝对字数目标尚未稳定遵守。新项目技术改动默认不覆盖旧源读取、云API协议或历史R2记录。
5. **这一轮是prompt/机制操作实验，不是WF从这三篇作品真实吸收全新作者写法，也不是语言模型参数训练。** 模型单评没有真人标定，未验证3→6→9闭卷迁移和50部完整作品总评；90%文学质量晋级不可凭模型均分单独通过。

## 已完成的保守底层补丁与工程保护

新增纯离线 `writerforge/reverse_story_context_evidence.py`：在真实聚合报告已从私有R2内容寻址readback且SHA核对后，提取**按任务SHA隔离**的正负候选，不包含任何原文或小说稿句子。对古杉林记 `NEGATIVE_ALL_FIVE_NEEDS_INDEPENDENT_REVIEW`，对另两篇记 `MODEL_POSITIVE_UNVERIFIED`。该补丁**不自动修改任何 Writer 规则、不删除旧技巧、不因为单个负例把整书/整个模型禁用**；它只是训练错误与语义适配策略的数据基础，配合合成单测防止历史良例退化。这个候选转换模块的真实R2上传尚未执行；三组原始/聚合R2实际已保存。

所有此前的第1窗口文学门闩继续保持 `NOT_PASSED`，正式第二窗口 `LOCKED`。若需要人类逐字盲审，未来须预先授权在**私有**位置有限留存匿名原创练习稿；本轮只保存文本SHA/脱敏短评，**不能复原已经销毁的两组三篇小说全文**。
