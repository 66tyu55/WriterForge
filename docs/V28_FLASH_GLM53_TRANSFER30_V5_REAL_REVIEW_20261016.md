## 3. 用户要求的无技能基准30

新版本 `writerforge/reverse_score_scale.py` 是**显示坐标校准**，没有向批评模型发送“必须给无技能30分”。计算规则：

`raw_baseline_mean = 82.8`；
`display_baseline = 30.0`；
`display_skill = 30.0 + (90.0 - 82.8) = 37.2`。

因此本轮新显示标尺 **30.0→37.2**，真实分差仍 **+7.2**。原始模型评分仍是82.8→90.0并永久保留。此转换不能将37.2解释为独立文学绝对能力，也**不能**将原始90.0当作真人认可的文学大师90%晋级结果。独立审评与3→6→9仍不满足。

## 4. 审评短评支持什么（和不支持什么）

评审引用的是两篇匿名原创稿及共同任务，没有收到本轮原著 `source_context`（本轮先前 P0 修复已部署）。其文本观察：

- **感知+7**：无技能稿依靠铃、雪、霜等意象，但部分概括；WF稿的雪声、配重刻痕、水汽、指头感触随角色动作逐层验证，更接近维修学徒自然识别异常。
- **因果+8**：无技能稿对是否报警犹豫，关键决定和后果展开不够；WF稿对鼓轮和手车两条路线做取舍，维护职责引导行动，肩伤、灯油消耗成为可观察代价。
- **信息+8但仍仅88**：WF有“配重与鼓轮矛盾→缆上痕迹→油布信”的先后，优于过早揭示的基线；然而结尾“它”的对象仍不明确。可以把“已展示、可回查但仍未解答的线索是否足够”列为下一次验证的文学缺口，不能硬插一个宿主技巧就自称修好。
- **连续+7**：WF在发现、出车、返回的时间线上有刻痕、钥匙、灯油回扣；基线的早期配角与后段时限较弱连接。
- **语言+6但仍89**：WF凝练动词、冷峻感官较佳；未超过90，不等于经过真人读者验证的成熟文风。

本轮 Planner 选择宿主预置 `GOAL_FILTERS_ATTENTION` 和 `COST_VISIBLE_IN_ACTION`。**都不是 WriterForge 新从原著发明的技巧**，只是把第一窗口的原著证据与宿主允许的安全操作作了关联。
