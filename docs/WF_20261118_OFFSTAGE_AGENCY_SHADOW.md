# 2026-11-18 WF 人物场外自主性试验（SHADOW）

**目标**：读者不被告知角色的每一个欲望、手段与选择，甚至看不到某些人的行动；但故事之外的世界仍能自行运转。角色的私心可以是求生、怯懦、利益、误会、善意和漠不关心，不等于人人都在策划阴谋。

**注意：本轮是单一作者写作示范，没有真实多模型隔离推理或强模型 A/B。不能宣称人物已经“自主思考”，文学效果也未经外部盲评。**

## 为什么比轻量状态卡多一层

旧 WF 的 V114/V116/V117 与 NarrativeCore 能存储世界事实、人物知识与 `immediate_intention`，但一个人物只有历史卡片不等于他会依据新情势改变主意。拟议实验不是七 Skill 继续参数化，而是**在写作前另行确认：人物可以在主角不在场时自行作决定、改变决定，结果不一定有人向读者解释。**

1. 各角色只获得公共事实 + 自己所见所闻 + 自己的当下关切；不知道其他角色秘密。
2. 角色独立作出下一步选择；允许等待、误判、没有变化或改变决定。环境事件不是某人的剧本。
3. 世界层只合并实际可执行的动作和结果；失败的打算不会被写成已发生事实。
4. 写作模型只拿到当前视角确实能看到的事件，私心、隐蔽动作、幕后全图**绝不自动混进正文提示**。
5. 读者可以看到0条、1条或少量痕迹；不能为了“埋伏笔”把每个人的心机都写成异常动作。
6. 主角离场后，其他人仍可行动。换掉主角性格，只改变受其影响的关系，水位、物价、别人的利益不自动暂停。

## 本次原创示范

正文见 [`experiments/wf_20261118_hidden_agency_scene.md`](../experiments/wf_20261118_hidden_agency_scene.md)。场景只以阿芷能知道的外界叙述；主角关心铜壶工钱与母亲药费。渡娘独自离港、米铺搬板、巡渠吏未贴新纸、自然涨水并不因主角在场才发生。

为防止事后硬凑“作者其实早安排好了”，暂定以下作者侧未通过独立检验的**多种可能，而不是正文已经暗示的唯一真相**：

| 人物 | 当前关切及认知界限 | 可变化的行动 |
| --- | --- | --- |
| 茶棚掌柜 | 担心封渡口后客人减少，不清楚官方最终决定；另可能有个人旧账 | 付钱、欠账、关门；壶嘴焊痕只是阿芷的普通生活顾虑，不强制变成幕后线索 |
| 巡渠吏 | 知道纸面新旧公告可能冲突，不能直接推定上级串通 | 暂不贴、再问、按错令贴；行动要受实际官规约束 |
| 渡娘 | 想到西岸接人，未必能穿过变化的水势；不知道小吏私情 | 出航、改道、折返；出港不等于已成功抵达 |
| 米铺庄二 | 想防潮保住米，不一定想涨价或哄抢 | 搬货、暂不涨价、少赊货或帮助邻人 |
| 未知西岸人 | 可确认有人搬竹筛，身份、私心、结果一概未明 | 不必后续解密；不是主角事件的附属线 |
| 阿芷 | 只想结算壶钱、抓药，没能力观察所有渡口政治 | 可以应门也可以不应；不代表任何决定都产生重大反转 |

**反事实**：阿芷即使当天不来，天仍会下雨、河仍会上涨，米铺仍有自己的生计压力。她应门或不应门可能只影响自己的认知，不必自动救全城。渡娘出航并非必能回港。

## 当前发现与问题

本示范确有不同人物在主角视野之外的生活，但有两项明显自我批评：
- 铜壶、告示、解缆、木梯等连续出现，会让正文显得“刻意安排了谜题”。以后要控制线索密度，不必每个物件都有后续答案。
- 作者在一份文本中设计多个私心仍非**真正独立角色推理**。只有未来真实独立隔离的角色决策和同题 A/B、读者盲评能判断是否降低“编排感”，不能把这篇示范当作证据。

**后续公平实验**：同模型、同题、同生成预算，A 只写自然续章，B 为各角色分别隔离生成有限视角下的一个决策后，汇总可观察世界事实给同一写作模型；原始各角色决策、失败、场外动作、作者正文都留存，检验正文是否反而更生硬；不能将独立多个角色多花的 token 排除在成本之外。未取得确定预算/合适调用接口之前，不擅自发起新的付费请求。

## 边界

这一批只增加故事示范和研究记录，不加入第二个数据库、世界引擎、内容校验器，也不修改正式 WF 的 NarrativeCore/V114-V119、main、Railway、XuehaiStore、R2、Canon。若不改善文学自然度，保留结果并停止扩展。
