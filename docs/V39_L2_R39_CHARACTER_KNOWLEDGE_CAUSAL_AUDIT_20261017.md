## 可自动验证与不可自动判定的边界

新增 scripts/audit_v39_r39_knowledge_causality.py 复用真实R2负对照与V38交叉审计，检查冻结正文SHA、句子编号、R39/R43引文原始位置、其间句子以及R34/R35/R37–R44早晚候选的哈希、字符范围和是否逐句原样出现在904字初稿。只把**句子元数据和判定缺口**写入新的私有不可变R2审计，回读确认SHA；公共日志不输出正文或人物详细心理描述。无模型调用。

不能因为R39比R43早，或两者引文真实存在，就得出以下任何结论：

1. R39是否首次引入同一物件/消息，还是已经在R34/R35等句铺垫后的回收；
2. 人物在R39之前实际知道哪些信息、是否具有可成立的判断依据；
3. R39是否改变人物目标、相信的事实或采取行动的可能性；
4. R40–R42是否含由R39而非其他事件导致的行为转向；
5. R43究竟回收R39、R34/R35还是其他更早细节；R39是否同时承担回收和二次铺垫。

纯代码无法直接从短句序列证明这些语义因果。**严格的结果应为 CONTESTED_NOT_RESOLVED，不是 L2_FAILED 或 L2_PASSED**；需要独立近读原作并逐句填写溯源、人物知识和行动依据。若真实R2未授权执行，不能宣称完成了该部分实跑。

## 运行与安全边界

只在既有私有R2环境（且有R2依赖和WRITERFORGE_R2_*权限）运行：

    python -m scripts.audit_v39_r39_knowledge_causality

本地合成回归：

    python -m unittest discover -s tests -p 'test_v39_*.py' -q

运行新脚本会仅在新 writerforge/v1/examiner/v39-frozen-L2-knowledge-causality/audits/ 前缀写入内容寻址审计并读回。它不写任何旧键，不传 DISCOVERY_API_KEY，不请求模型API，不替任何读者/评审生成文学判断。正式窗口仍 first=NOT_PASSED、second=LOCKED。

**后续停止条件**：若任一冻结SHA或 R39/R43 与V38句子编号不一致，立即报错；若无私有R2访问只记录「未执行」，不能出具新R2审计SHA；若证据没有独立人物知识/行动链，保留「无法确认」，不可用硬编码百分比或重复评分挤出有利答案。
