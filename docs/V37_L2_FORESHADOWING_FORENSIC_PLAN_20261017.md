## 为什么检查 L2

真实私有 R2 的 V36 证据回放已明确：两段第1/2回各2000字符、4条原著观察、2条自主提炼手法 L1/L2、7个写前决策中**只有 foreshadowing 明确引用 L2**；WF 对目标/知识/因果/场景给过4条真实正文引文，却完全没有验证唯一新学手法 L2。此时若宣称WF“从《西游记》学会伏笔”，属于证据不支持的结论。

本轮不再训练，不改原文、不换考试题、不修改原有904字第一稿与1136字修改稿、不给正式技能晋级。**只针对L2**判断是否存在以下五类缺口：原文依据不支持、抽象理解偏差、写前选用不合适、写作执行不到位、证据不足。不能只凭写后自述结论。

## 固定断点，按顺序独立检查

1. **BP1 来源段落**：只从内容寻址的V35 stage0/1/2恢复同一个2000字原著连续窗口，以及 L2 对应的真实原著观察。机器检查引用原文确实存在、`L2.source_observation_index`指向读书记录中的一项。语义效果是否正确仍是待独立评审的假说。
2. **BP2 抽象手法**：检查 L2 的 `technique / why / use_when / avoid_when / verification_question` 原样存在，找出它的叙事功能，而不是再编造原著后续故事。
3. **BP3 考前适配**：读取真正 **stage3冻结写前构思的 foreshadowing 条目**，核验 `learned_lesson_id=L2`、选择原因、舍弃手法与预期读者效果。此条目在写作前已写R2，之后不能编辑。
4. **BP4 下笔落实**：复用内容哈希锁定的904字符原稿和1136字符修订稿，考官程序按正文标点和起止位置制作可验证的句子ID菜单。独立审评者**必须按真实句子ID**指出“早期铺垫”和“后期回收”分别是什么；若找不到允许 NONE，**绝不能为了格式假造伏笔**。比较伏笔原稿是否有、是否修订后才出现。
5. **BP5 独立判断与分歧**：由与学习的Flash/写作的GLM均不同的 DeepSeek V4 Pro 与 MiniMax M3 各自单独审阅，彼此不看对方结论与既往成绩。每个评审分开返回来源理解是否成立、适用条件是否匹配、原稿/修订稿兑现与否、结尾前后线索的支持度，引用对应句子ID和可质疑之处。保留不同意见**不取平均**。必须由宿主重新验证所有句子ID、相对顺序、评分格式和证据指向；若返回无效，不存在“缺分算满分”。
6. **BP6 不可变结果**：对原来6个阶段和V35原始失败、追加写后补测所有SHA再次核验，独立评审的每次**原始回复先私有R2存档再校验**；生成新的不可变V37结果+散列，公共Github Actions日志只打印结论枚举、句子ID与SHA，不泄漏私有原文、原创新稿和详细写前思考。
7. **BP7 根因归位**：若原著手法未支持，`SOURCE_SEMANTIC_UNSUPPORTED`；若源支持但新场景不适用，`TASK_SELECTION_MISMATCH`；若考前安排合理但没有可回查句子，`EXECUTION_NOT_EVIDENCED`；有形式证据而文学效果不足，`POSSIBLE_WEAK_EXECUTION`；模型意见冲突/字段不全，`NOT_ESTABLISHED`。这些只作候选诊断，不能据单题推断稳定文学能力进化。

## 控制

- 两名外部评审模型每名最多2次请求，只有结构错误才允许额外一次，同一冻结资料不得换题换稿；总最多4次API请求和约25k预留输出tokens。**不生成任何新小说或WF新规划稿**。
- 使用私有R2 `writerforge-private-library`，任何完整材料或模型私有评审意见都不能写Github公开日志/仓库；脚本输出只给非敏感metadata。
- 所有真实A/B旧试验、first`NOT_PASSED`与second`LOCKED`、50作品要求不变，零正式技能晋级。
- 独立两模型评审仍不等于真人证实；引用真正存在≠语义一定正确。若审评无法完成，以证据不充分结束，不造结论。

**预期验收**：能回答“是学错、选错、写错，还是缺证据”，必须同时区分原稿和修订稿；绝不只返回一个总分。
