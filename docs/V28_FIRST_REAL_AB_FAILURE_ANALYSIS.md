## 2. P0：真正的关键缺陷——原著剧情被当成写作技法输入

可检查的代码：[reverse_cloud_ab.py](../writerforge/reverse_cloud_ab.py)。

Planner 对原著第一段输出自由文本分析，系统直接取其中 perception、decision、author_mechanism 三个完整文字字段，原样放入 Writer 的 technique_constraints。

**实际 R2 文件证实，这三个字段并非抽象的技法：里面包含林动、林啸、柳妍、受伤、父亲让出修炼资源、家族地位等书中具体人物和情节。** 模型被提示“换个原创故事”，但仍收到了原著情节轮廓，增强组与基线的对照因此被污染。

批评模型对增强稿描述的情节也围绕受伤、家庭牺牲和身世秘密。可以确认“写作提示含具体原著剧情”；由于原稿已经删除，还不能断定最终稿逐字或实质侵权。现有字面查重只针对约30字连续重合，挡不住换词复述原著结构。

正确迁移对象应为：
- 角色因既有目标和记忆而选择性注意刺激
- 可观察的牺牲和行为后果建立动机可信度
- 先给可回查线索，再延迟解释，形成有效读者悬念
- 内心转折要有能够感知的事件、代价或冲突作支撑

**不应该迁移具体角色、药材、武技、身世秘密和家庭事件。**

## 3. 其他已证实问题与待验证假说

**程序事实：**
- Skill 组添加的是三个自由文本字段，不是经过严格标识的写作操作。它们既没有与原著人物知识状态分层隔离，也没有保留前因后果的独立证据校验。
- 同一写作任务的两稿没有长度差上限；只有单组 A/B、单一批评模型，缺少重复样本和人类校准。
- R2 只保存一次报告和哈希，没有真正接到 V28 faults、forgetting、已审核/未审核核心的完整状态机；没有进行间隔遗忘复测、双段合并或新任务迁移。
- 模型批评者同时是原著技法规划者，可能产生偏好相关性；虽然使用稿件 SHA 排序匿名 A/B 标签，但独立性仍不足。
- 删除练笔正文后只剩模型简短批评，不再具备对同一稿独立复评所需的可读证据。删除应放在全部受控审核与来源检查完成后。

**来自批评但尚不能证明成因的假说：**
- WriterForge 技巧文字过长、过于具体，可能诱导写作者“解释人物心理”而不是通过感官和动作表现。
- 直接移入原著家庭困境，可能有利于直线因果，却牺牲原创的感知层次和象征性语言。
- 用一个秘密当悬念，而没有先导线索，可能令信息释放仅停留在“抛设定”，没有可回查的读者推断。

不能把这些假说直接加入高信任文学核心；下一次必须通过公平的反事实实验验证。

## 4. 建议修复优先级

**P0（必须先修，禁止直接重复收费 A/B）：**
将 SourceCharacterState（原著人物/事件/认知，只给 Planner 和 Critic）与 TransferableMechanism（只给 Writer）严格拆开。Writer 只能接受宿主定义的技巧 ID 和无原著人物的可执行写法，例如 GOAL_FILTERS_ATTENTION、COST_VISIBLE_IN_ACTION、WITHHOLD_CAUSE_SHOW_CLUE、EMOTIONAL_TURN_WITH_EVIDENCE。Planner 选择这些类型并提交原文证据 ID，不能把原文具体事件以自由文本塞进生成器。加强提示词流向、专名、剧情复述的检测。

**P1（确保实验有意义）：**
相同世界设定自由度、任务、模型参数和输出长度范围；如果 A/B 实际长度差超过15%，标记实验不具可比性，不计算胜者。不以是否与原著相似作为加分项。引入完全不同的评审模型或真人复核，要求评分理由指向具体的创作机制和文本证据。

**P2（形成真实学习闭环）：**
每次模型批评将“明确失误 / 遗忘 / 可迁移假说 / 反证 / 置信度 / 未解决问题”分别写入有界数据库；经验候选先待审核。完成独立审评、来源检查、私有 R2 全新恢复后才删除隔离草稿。之后用新人物新冲突闭卷重测，跨不同场景累计 3→6→9 个独立证据；不得将同场景重复试写算作新证据。

**P3（用户原来定下的第一章连续性）：**
第一章先建立“人物当时已知、误信、目标、选择、后果、未解问题”时间线，第二场景继承此状态；自然场景分界通过语义确认，而不是取长度中点。单段、两个相邻段合并和新情境迁移都须分别过关。

## 5. 应保存的失败核心（全是候选，不可晋级）

- F-V28-001：因果链清楚不等于人物感知自然。感知需由既有目标/情绪/信息上限引发，而不是设定台词直接交代。
- F-V28-002：两稿悬念都缺少充分线索，必须把“后文可回查的线索”与“暂不解释”结合。
- F-V28-003：原著专名与具体事件进入 Writer 提示词，造成实验污染。这是程序级 P0，不是文风偏好。
- F-V28-004：增强语言表达更直白、心理转折偏快，可能与过量机制说明有关；仍需下一次对照检验。
- F-V28-005：等长与独立复核不足、原稿已删，单次数字不能代表技能能力变化。

## 6. 验收结论

**第一窗口：NOT_PASSED；第二窗口：LOCKED；90% 大师水平目标：NOT_VERIFIED。**

最重要的改进不是再换模型或继续循环刷分，而是让“从原著学到的东西”真正从剧情事实升维成可检验、可应用的叙事动作。下一步优先增加离线失败用例：把原著姓名/剧情输进 Writer prompt 必须被拦截；A/B 长度差过大必须阻止比较；不同世界的因果技法重现才算有效。
