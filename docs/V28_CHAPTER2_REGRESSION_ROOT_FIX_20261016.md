## 三、退化具体表现和必须区分的根因

本轮模型短评指出：

1. **感知变成操作清单（-4）**：WF稿滑轮声、粉笔线、油痕、拖痕等机械细节堆积，而不是一个目标引导读者观察的感官链。无技能稿“发现温热缆段→触觉验证→听到规律细响”更自然。
2. **决策理由不足（-2）**：WF故事里“先挂梯再敲门”的关键选择主要依赖师父规矩，不足以支撑显著风险。可观察行动代价是有了，但动机与两条真实可行选择之间的连接不足。
3. **线索失焦（-3）**：同时展示粉笔线、湿圈、油痕、滑轮毛刺等多种线索，但缺少一个推动本场景人物决策的主线悬念。上轮信息释放88、此轮降至82，不能仅靠“更多异常名词”提高。
4. **时间承接偏硬（-2）**：从夜巡到醒来时已过三更，缺少自然的过渡，削弱时间压力。
5. **语言沉入记流水账（-3）**：动作细节真实但文学节奏、意象密度、句际张力弱于无技能稿。

这些**是批评模型对已生成文本的观察**，草稿没有长留，独立真人无法对同一稿全文复核。不能断言“第2章的原著内容导致机械描写”，因为机制 ID 一样、模型采样随机，也缺少第一章语境继承。

更深的代码层缺陷：
- `parse_selections` 当前只验证 ID 是现有四种宿主技巧以及 evidence ID 确实存在，**未验证该段落语义真的支持机制**。Planner 必须选1~2个，不能可靠地“无技可学则弃权”，所以会强迫新章节匹配旧有技巧。
- Writer 只收到静态技法文字，不收到原著剧情是正确的版权/原创隔离；但也意味着词汇层“机制”过于粗糙，缺少 **何种任务适用 / 何种情况下应禁用 / 验证读者感知的最低条件**。
- 之前练习绝大多数来自第1章，未有跨章持久、且已核实的人物知识状态。越章诊断因此能够揭示迁移弱点，但不能证明整个章节续写连贯能力。
- V5 模型好分不等于 Skill 已自动内化；底层只能从实证构造“模型观察候选”，不能直接升级为永久写作提示词规则。

## 五、真正有效的下一策略（尚未实现/验证的文学层功能，不能装作已修好）

- **不再追某一段高分**。按章节连续采样、跨不同人物任务，每章只测试新来源，而不是反复改第1章；每轮与上一轮固定模型/创作任务做一组对照，负例照存。
- **添加可弃权的机制选择**：原文如无可证机制时返回零选择并生成无技能故事，不得强塞GOAL+COST。语义证据审核须能检查“源句在人物当时已知什么、为什么被注意、这一观察怎样影响行动”；这项独立文学验证尚未做。
- **按上下文版本管理经验、自动拒绝未验证机制覆盖**：保留v5“有效候选”与v6“反例”；两者不能互相删除、不能因新内容负向就废弃所有旧函数。只有多场景独立评审才提升层级。
- **在原创审稿环节加因果与信息释放的独立证据链**：目标→感知→判断→选择→行动→不可逆后果，以及线索→角色可见→读者可回推→延迟答案。强调结构正确，也要校验语言自然、故事中心有没有被细节清单淹没。
- **闭卷迁移采用负向保护**：新章候选一旦低于相同模型基线，进入隔离区，默认不作为通用写作规律。下次补真人独立评审与更多样本，不能用反复付费碰高分代替修因果逻辑。
