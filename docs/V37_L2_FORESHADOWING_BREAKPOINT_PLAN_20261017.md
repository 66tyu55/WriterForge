2. **ABSTRACTION**：核对 L2 的 technique/why/use_when/avoid_when/verification_question，区分原著事实与抽象假说。
3. **PLAN**：锁定 stage3 的 foreshadowing 决策及其理由、放弃方案、预期效果，确认其确实绑定L2。
4. **FIRST_DRAFT**：在904字符首稿中查找可能承担伏笔功能的前置细节、角色认知和后文回扣；不把普通物件出现当作伏笔成功。
5. **REVISED_DRAFT**：同样检查1136字符修订稿，区分原有与后补细节，验证是否形成首尾因果。
6. **JUDGMENT**：分类为原著误解/抽象过度/场景选用不当/写作未执行/复盘漏检/证据不足，允许多项并存，但必须分别引用实际证据。
