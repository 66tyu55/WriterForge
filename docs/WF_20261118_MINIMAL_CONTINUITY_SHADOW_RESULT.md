## 为什么转向

已核实的旧证据：

- [0.EO 当前交接](WF_ACTIVE_BRIEF.md) 记录 0.EM/0.EN 真正付费强作者模型的写作实验：有漂亮可读的正文，但也出现“寡妇的亡夫被写成活人”“旧桥许可与载重冲突”“腰伤者被指派重体力活”等。原始强模型 A/B 正文保存在短期 Actions artifact；本轮当前未能取回完整原稿，**不虚构原始引用、模型新回复或新准确率**。

已有 V114/V116/V117 的候选状态检查及 V119 的局部修订；不能为了新结论重建第二套数据库、学海、完整审稿器。七 Skill 原有 PR #73 不删，但不作为作者生成正文前的强制门槛。

## 目标与权限

作者模型：自由写，允许不理性选择、错误信念、梦、叙述视角、即兴伏笔、超自然意外。WF：只对**已经从原文确认的重大状态**提供简短上下文；出现有来源的风险时提出可拒绝的复核建议；不做整段重写、不让机器冒充文学裁判。一个故事可以既有世界因果，又有人物犯错和不可预料事件。

短状态卡参考：贺蘅=寡妇/亡夫；旧桥=只能空车过；胡四=腰伤未愈；井符被矿主移走=未经证实的传闻。状态卡应附真实原文来源、时间及认知层级；这些示例取自旧 0.EN 题设与事后审查的**简化测试材料**，不是新抓到的原始模型正文。

## 这次真正运行了什么

单独实验代码 \`experiments/wf_light_continuity_probe_20261118.py\` 仅接收人工标注并逐字存在于小段 \`prose\` 的事件/状态；比对一条已人工复核的旧状态与一条未复核的新叙述候选。**不解析任意整章中文，不判定语义正确，不写 Canon。**

人工事先列定 **8 个合成用例，8/8 与预期分类一致；4 个单元测试通过**：

| 用例类型 | 数量 | 当前响应 |
| --- | ---: | --- |
| 亡夫无解释复活、桥未经修复承重、腰伤无故痊愈 | 3 | \`UNEXPLAINED_CHANGE_REVIEW_ONLY\` |
| 桥有明确修复经过 | 1 | \`EXPLAINED_TRANSITION_REVIEW_ONLY\`（说明仍待复核，不自动证真） |
| 人物做梦、带伤仍执意劳动、传闻仍保持为传闻 | 3 | 不当成客观世界矛盾 |
| 传闻直接升格为叙述者断言 | 1 | \`NEW_NARRATOR_ASSERTION_NEEDS_SOURCE_REVIEW\` |

此外拒绝引用不在候选正文里的伪造文本、拒绝未经复核的旧状态被标成可信依据；所有状态为候选，**0次模型调用，0付费，0生产/Canon/R2写入，0强制改稿**。

注意：8/8 是**已知、手工标注、人工预先指定答案**的接口测试，绝不是盲测准确率、泛化能力或对作者文学增益的证明。对上下文漏抽、叙述复杂转折、梦中动作、大量人物，当前完全未测试。

## 下一项决定性实证

选择两种未用于本次测试的玄幻续章场景，冻结同一前文与角色真实状态：
- A：强模型正常写，不加 WF 前置约束。
- B：同一个模型、同一题、同档预算，只多一张**不超过600汉字**的、源文可查、非强制世界状态卡。注意 B 的额外 prompt token 必须真实计成本。
- 每篇完整原始构思/正文保留，匿名独立读者从人物行为自然、事实连续、语言体验判断，列出新发现的真错、漏报与误报。每篇的历史/叙述时间和真实状态需跟踪；不可以拿本次 8 个合成测试当验收。
- 只在目标已明确且有模型调用预算授权的情况下另行运行真正的强模型生成；**本次没有调用新模型**。若成本增加、错误未减少或文学自然度下降，停止此路线；保持旧七 Skill 的研究状态，不合入 main。
