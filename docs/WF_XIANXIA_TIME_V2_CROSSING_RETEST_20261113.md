## 预注册验收

1. **机械参数**：两组世界与所有 NPC 的时钟相等；洞中倍率改变了角色累计修炼时间；离洞后采用洞外倍率，不允许继续按3倍流速计算。
2. **行动约束**：若作者在1:1组宣称此刻成功突破，内核拒绝；3:1组允许成功尝试，但不强制必定突破。普通警钟、求援、撤离可以在两组合法出现。
3. **自然小说**：有实际行动与后果，人物不突然获知未接触的信息；不能只写“他决定做点什么”。若存在小说与行动账不对应，记录为失败。
4. **方法的边界**：由于两组可能自主选择同样的合法行动，单次结果不能反推出“时间参数让模型选择更好”；尤其不能认定已经从原著学会修仙时间。只有外部审核的多场景对照才能证明提升。
5. **停止**：如实际作者不遵守规则或文学质量退步，保留模型原始回复和首个失败点，不再把继续增加参数当作进步；原先 river 场景不改写、不重试。
