# 真实场景深读试点：红楼梦第三回 → 《渡口无名簿》已有失败稿

**证据源**：Project Gutenberg / GITenberg 公开中文原文 #24264，WriterForge 原有固定 Git blob
`4f75f649a922cb1d3576b40e5ccd15baf367b594`。
GitHub Actions 必须从这一版下载、完整校验后再运行 `scripts/classics_pilot.py`。
场景位置：第三回“林黛玉入贾府至王熙凤初见”。不使用现代译文，也不把本文解释算作作者批准的事实。

**失败稿**：《渡口无名簿》三章试读（已存在作者文件库）；这是此前 M0 对话创作稿，
不是 WriterForge 正式模型管线的因果实验。这里只做局部诊断，避免再完整重写三章。

## 一、先看原著到底如何组织情节和语言

| 阶段 | 原文可核对的证据 | 暂定文学机制（解释，不是客观测量） |
|---|---|---|
| 人物入场 | “步步留心，時時在意” | 黛玉听闻外祖母家不同，初来者的谨慎先成为观察条件，不把宅第单写成豪华景物 |
| 空间秩序 | “正門卻不開” | 门、轿夫、仆役更替让人察觉权力结构，读者随初到者逐渐学会规则 |
| 人物反差 | 后院突有笑声，王熙凤进入 | 读者先见群体肃静，再见来者似乎可以打破这种秩序；人物的地位通过他人反应显露 |
| 言语试探 | 王熙凤当众赞美黛玉 | 称赞同时顾及贾母对外孙女的关切。这是否显示迎合与权力嗅觉，须结合后文验证 |

**反事实写法**：假如作者一开始便交代“这是权势森严的贵族之家，王熙凤精明能干”，
信息虽然都齐全，读者却少了与黛玉一起辨认规矩、再遭遇例外的体验。
这不是“禁止解释性语言”的绝对规则，而是场景中**信息出现顺序**可能承载的表达作用。

文本定位证据由 `writerforge.scene_learning.extract_verified_classic_scene` 核对；
保存的是场景和逐步揭示的哈希、章回及审计状态，非原文粗放复制。

## 二、映射到现成失败稿（针对具体段落，不是套模板）

《渡口无名簿》第三章的中心动作很清楚：叶芦通过改动白标竹诱使白牌船搁浅，
阿蓼喊回被当成死人的众人的名字，叶芦撬开总索，最终舍弃父亲留下的渡船。

局部问题不在于“没有动作、没有情绪”。恰恰相反，**事件执行太顺**：

1. 原先掌舵人已经察觉白标竹偏移，却仍很快驶向陷阱；阻止他的动机和外在制约尚弱。
2. 押丁持弩、三十二人脚带短链且行走缓慢，但主角团在有限抵抗中便能全员逃离；守卫后续阻击与撤离时间成本缺乏充分呈现。
3. 常七的人情、岗位责任与母亲安全之间已有冲突苗头，但拦弩时仅以官署记账作借口，他承担的**即时**危险没有充分改变结果。
4. 阿蓼喊名字很有戏剧潜力，但这一声除了转移押丁注意力，没有让更多角色基于自己的风险作出不同选择。

这些是**待读者验证的诊断**，不是自动确定的“文学错误”，也不是强制添加弩箭、反转或惨剧的要求。

**局部修订实验（不生成整章）**：

- **目标不变**：救回被抹掉姓名的人；保留叶芦舍船的关键选择。
- **变动一个变量**：阿蓼当众喊出名字以后，受害人、掌舵人和押丁分别知道了什么？
  谁因为被叫出真名而愿意冒险，谁反而更害怕报复？
- **先写决策，再写动作**：一个守卫可以因怕担责继续射弩；常七必须在同僚、母亲和逃亡者之间作出更有成本的选择。
- **检验信息次序**：先让读者看到异常反应，再解释原因；若直接总结“他们终于找回了尊严”，会损失什么？
- **停止条件**：方案若只是变得更复杂、但不更可信或更想继续读，就淘汰而非继续加 Skill。

## 三、可运行学习与验证门槛

这次新增的是**现有学海 SQLite 的场景读取环节**，不是第 N 个独立写作技能：

1. **source_prepared**：GitHub Actions 使用 #24264 固定版本，提取第三回场景、识别反转点和核对证据语句；没有模型调用。
2. **first_read_locked**：只有接入真实模型后，才让它先阅读**揭示前**的正文并将初步猜测原样提交到 SQLite。
3. **interpretation_unreviewed**：随后让它阅读剩余部分，每项写作机制必须引用原文中的真实语句，给出改变写法的反事实与迁移问题。
4. **人工或独立审查**：未经明确复核的解释不能被标记为可靠的文学经验，也不能直接影响 WriterForge 正文。
5. **失败稿 A/B**：只对既有的一段安排同模型、同条件对照；单项改善必须有盲评或真实读者证据，不能被单次模型自评冒充。

GitHub Actions 目前只负责第 1 步，在完成 R2 写入＋全新恢复后报告；
**未运行的阶段不得自动报告成功**。完整读者体验和文学质量的最终提升没有验证。

## 四、避免重蹈覆辙

- 不制造不存在的读者分数；模型“初读”不是独立真人读者。
- 不拿原著里的词频、声音、温度或情绪标签当作文学理解。
- 不把短小技巧卡或未审查的文学解释自动拼进正文提示词。
- 不新增 13 本合集或 GPT 临时存储依赖；单书仍归档在现有私有 R2。
- 没有成果时宁可显示 `source_prepared`，也不称“作者已经掌握红楼梦的文笔”。
