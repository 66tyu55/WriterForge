# V5 五条跨运行时能力闭环

V5 不增加第三种业务运行时。

仍然只有：
- LEARN
- WRITE

五个核心问题被设计成“成对能力”：

```text
LEARN side -> Published Knowledge -> Middleware -> WRITE side
WRITE side -> Experience Event / Gap -> Next LEARN or Project Model
```

重要：
- WRITE 不把正文写回 Xuehai。
- LEARN 不在学习过程中写小说。
- 创作产生的经验进入 `Experience Ledger`，不是 Source Corpus。
- 用户明确选择/否定的审美偏好可以更新 Project Taste，但不能伪装成原著证据。
