# 48A Taste Learn｜审美学习端（V12）

## 目标

LEARN 不只问“作者怎么写”，还问：面对多个可能方案，作者实际上选择了什么、牺牲了什么、读者后来感受到什么。

## 顺序阅读记录

```yaml
context:
chosen_move:
avoided_or_delayed_move:
reader_effect_now:
reader_effect_later:
tradeoff:
conditions:
confidence:
```

## 对照学习

优先学习“功能相同但处理不同”的对比：
- 克制 vs 直抒
- 留白 vs 解释
- Scene vs Summary vs Omission
- 明示心理 vs 自由间接话语
- 新意象 vs 旧母题回返
- 立即反转 vs 延迟兑现

## 产物

不是“好句列表”，而是条件性 `taste_evidence`。不得把某位作者的偏好提升为普遍真理。

原著顺序阅读证据、真实读者证据、当前项目偏好保持来源标签，不混成一个总分。
