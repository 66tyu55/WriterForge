# 50A Multiscale Learn｜多尺度文学学习

## 目标
解决“学会树叶、忘了森林”。

每部原著同时建立七层表示：

```text
Lw Word/Collocation
Ls Sentence
Lp Paragraph
Lc Scene
Lh Chapter
La Arc
Lb Book
```

## 各层学习重点
- Word：词域、搭配、文化边界
- Sentence：功能、节奏、信息顺序
- Paragraph：微目标、推进方式
- Scene：目标/阻力/转折/退出
- Chapter：章节承诺、峰值、结尾牵引
- Arc：长期变化、承诺推进、人物弧
- Book：主题演化、结构回响、意象系统、结局兑现

## 发布
每层独立索引，但保留父子链接。
