# 49B Discovery Write｜探索草稿端

## 目标
防止逐句系统把一切过早定死。

WRITE 内部增加三个阶段：
```text
DISCOVERY -> CRAFT -> REVISION
```

## DISCOVERY
允许：
- 临时细节
- 暂未解释的行为
- 多个方向分支
- 暂不进入 Canon 的试写
- 角色出现意外反应

禁止：
- 把探索内容直接标记为 confirmed fact

所有探索内容标记：
`PROVISIONAL`

## Promote
只有当探索材料满足至少一项：
- 揭示人物
- 产生后续因果
- 强化主题/意象
- 改善场景
才可进入 CRAFT 并更新 Canon。
