# Reader Effect Model

WriterForge 以后区分三种 Reader：

## 1. Source Reader
LEARN 中第一次阅读原著的“冷读者”。

价值：
建立“原著实际上如何驱动阅读”的证据。

## 2. Predicted Reader
WRITE 中隔离上下文的 Cold Reader Reviewer。

只能看到截至当前位置的正文。
不能看 Canon 真相或未来大纲。

价值：
预测：
- 还想不想读
- 在关心什么
- 在误解什么
- 情绪有没有发生

## 3. Actual Reader
真人 Alpha/Beta Reader。

优先级最高。

如果：
Predicted Reader 认为很好，
Actual Reader 普遍觉得无聊，

必须相信 Actual Reader 数据，而不是模型自评。
