# 子技能 07：主题与目标审稿器

## 目标
独立判断已写内容是否仍在服务主题、情节目标和人物目标。

## 输入
- 项目主题；
- 当前场景目标；
- 目标读者感受；
- 已写文本；
- 未来情节约束。

## 输出
不得只给“好/不好”。
必须圈点具体句子。

```yaml
finding:
  sentence_id:
  text_excerpt:
  issue_type:
  why:
  severity: note|warning|blocking
  suggested_action: keep|cut|move|rewrite
```

## 检查项
- 偏题；
- 情节停滞；
- 人物行为违背已建立动机；
- 提前泄露；
- 重复说明；
- 情绪没有因果；
- 场景目标已经完成却仍拖延；
- 与未来走向冲突；
- 主题被直接说教而非由事件体现。

## 不直接重写全文
审稿器只定位问题。
具体重写交回 03/04。
