# 子技能 01：原著顺序学习与 8 条线拆分

## 目标
完整、按顺序学习 TXT / Markdown / DOCX / PDF 等文学文本，并将每个最小文本单位同时映射到 8 条独立轨道。

## 重要纠正
用户要求“剧情/物品/人物/环境/时间/地点/感官/情绪 8 条线完整且单独分开”。
实现时每条线必须分别存储，但仍保留共同的 `source_span_id`，从而能回到同一个原文位置。

## 禁止关键词式学习
不得以“搜索人物名、动作词、物品名”等方式代替阅读。
必须按照：
`卷 -> 章 -> 节 -> 段 -> 句`
依次读取。

若文件过长：
- 用游标继续读取；
- 每一批结尾保存 `next_cursor`;
- 下一批必须从该游标继续；
- 不得从搜索结果跳到后文。

## 8 条轨道

### 1. 剧情 Plot
记录：
- 当前发生了什么；
- 谁改变了局势；
- 因果关系；
- 信息揭示；
- 冲突升级/缓和；
- 伏笔、回收；
- 场景入口和出口。

### 2. 物品 Object
记录：
- 具体物品；
- 材质、形态、磨损、声音、重量、携带方式；
- 与人物身份/剧情的关系；
- 物品首次出现、再次出现、状态变化。

### 3. 人物 Character
记录：
- 人物出现顺序；
- 动作；
- 说话方式；
- 观察焦点；
- 身体反应；
- 关系变化；
- 知道/不知道什么。

### 4. 环境 Environment
记录：
- 光线；
- 天气；
- 建筑；
- 植被；
- 声场；
- 空间尺度；
- 可通行性；
- 背景动态。

### 5. 时间 Time
记录：
- 明确时间；
- 相对时间；
- 持续时长；
- 节奏快慢；
- 闪回/预叙；
- 时间跳跃。

### 6. 地点 Location
记录：
- 大区域；
- 当前场景；
- 人物相对位置；
- 出入口；
- 方位变化；
- 地点与情节功能。

### 7. 感官 Sense
单独拆：
- 视觉
- 听觉
- 嗅觉
- 味觉
- 触觉
- 温度
- 疼痛
- 平衡/重量/肌肉感

### 8. 情绪 Emotion
记录：
- 明示情绪；
- 未明说但由动作体现的情绪；
- 强度；
- 变化触发点；
- 人物是否隐藏情绪；
- 读者被引导产生的情绪。

## 学海库存储

每个句子建立一个 source_span，8 条线分别引用。

```json
{
  "source_span_id": "work01-ch03-p012-s004",
  "work_id": "work01",
  "location": {"chapter": 3, "paragraph": 12, "sentence": 4},
  "text": "原文句子",
  "tracks": {
    "plot": [],
    "object": [],
    "character": [],
    "environment": [],
    "time": [],
    "location": [],
    "sense": [],
    "emotion": []
  },
  "craft": {
    "sentence_function": "",
    "transition": "",
    "rhythm": "",
    "specificity": "",
    "show_vs_tell": "",
    "information_order": ""
  }
}
```

## 词汇库存不是简单词频表

每个词或短语存：
- 词形；
- 来源位置；
- 语义角色；
- 搭配对象；
- 适用场景；
- 情绪色彩；
- 感官类别；
- 是否为专名；
- 是否允许直接复用；
- 是否容易形成原文近似。

推荐：

```json
{
  "term": "潮湿",
  "source_span_ids": ["..."],
  "roles": ["environment", "sense"],
  "collocations": ["石壁", "衣襟"],
  "register": "neutral",
  "reuse": "common_word"
}
```

对独特表达：
`reuse = technique_only`

## 完成条件
一部作品只有在：
- 顺序游标到 EOF；
- 章节没有跳号；
- 每个 source_span 都有 8 轨字段（可为空数组）；
- 抽样回查能定位原文；
才标记 `study_complete=true`。
