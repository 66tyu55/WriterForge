# 子技能 10：学海库词汇 / 命名门禁

## 目标
禁止 AI 在受约束内容上随意随机。

## 受约束内容
强制校验来源：
- 人名；
- 地名；
- 门派/组织名；
- 武器/宝物/特殊物件名；
- 独特称谓；
- 世界专用术语；
- 已规定必须遵循原著词域的描述性词汇。

## 非受约束内容
不应机械限制：
- 的、了、着、却、于是等语法/功能词；
- 常用基础动词；
- 为保持语法自然所需的一般词。

否则文本会退化成拼词游戏。

## 来源优先级
1. 用户当前明确设定；
2. 当前项目实体库；
3. 学海库中 `reuse=entity` 或 `reuse=common_word`；
4. 经项目总控批准的新实体提案。

没有来源：
`BLOCKED: UNSOURCED_ENTITY`

## 新实体提案
如果用户允许原创世界扩展：

```yaml
proposal:
  type: location
  function: 山道驿站
  naming_constraints:
  derived_from_xuehai_patterns: true
  candidates: [...]
```

注意候选名不得直接复制受保护作品中的独特专名，除非用户明确在该作品的授权/同人范围内使用。

## 词域校验
对于场景核心词，优先从学海库找同类：
- 夜雨场景 -> 雨、瓦、檐、水声、湿冷等已学词域；
- 战斗 -> 动作与身体感，而不是随机华丽形容词。

## 防机械拼装
门禁只决定“可不可以用”，不决定“句子怎么写”。
句子结构仍由 03 决定。
