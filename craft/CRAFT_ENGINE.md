# Craft Engine｜轻量文学技法引擎

Craft Engine 负责“怎么写出来”，但不是常驻 Prompt 栈。

## 五组不扩张

1. Dialogue Action
2. Perception & Description
3. Cognitive Motion
4. Narrative Restraint
5. Scene Turn & Rhythm

新增技法优先作为组内 Technique Card；只有诊断对象、干预机制、失败模式都明显不同才允许 Skill Birth。

## Scene Craft Contract

正常流程：

`Scene Plan -> Craft Router -> 0-2 cards -> Scene Craft Contract -> Draft -> Boundary Check`

同一场景中，只要 POV、人物目标/知识、Scene Plan、Reader Question 等关键依赖未变，就继续复用合同，不逐句重跑 Router。

## 强制原则

- 最多激活 2 组。
- 技法选择服务 Reader Effect / Character Truth / Scene Function，而非追求“高级感”。
- Craft Auditor 只指出失败，不自动 humanize。
- 安静场景可以合法存在；没有外部大事件不等于没有 Delta。
- 固定感官数量、固定句长、固定对白比例禁止进入核心。
