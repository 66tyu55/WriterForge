# 气氛与文学表现（独立 Skill，未训练完成）

负责场景气氛、感官线索、叙事视角、文字节奏与表现手法之间的关系。它研究“何种原著细节造成何种阅读效果”，**不生成固定修辞模板、不抄写原著正文、不把气氛当物理世界规则**。

完整原著私有阅读保留原文＋批注＋心得。独立参数候选应引用源位置、场景窗口、可观察意象、描写处理方法、其他可能解释和可能失效的环境。气氛是读者效果/作者技法的分析假设，不是人物必然拥有的心情。

空间 Skill 的地理/光线、人物情绪 Skill 的反应可提供只读候选，但互不修改各自参数。联合训练后必须独立分析未见章节的气氛，而非直接复制他人给出的结论。文学质量须通过盲评而不是关键词计数。

当前仅 Skill 研究方向，**不代表文学能力增长或完成训练**。SHADOW，禁止自动写入 WF 作者、学海、R2、Canon。
