# Experience Ledger｜创作经验账本

它不是学海库。

用途：
- 保存用户偏好事件
- 保存成功/失败的 Project decisions
- 保存 Discovery 的 promote/discard 结果
- 保存 Emergence Proposal 的批准/拒绝
- 保存 Rewrite 结果

禁止：
- 把 AI 自己写的句子当原著学习证据
- 自动提升为 Xuehai quality evidence

LEARN 可以读取“缺口”和“用户偏好摘要”来决定下一批学习方向，
但必须保持来源标签：
`source_type = project_experience`
